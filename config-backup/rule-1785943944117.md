1. 信息边界：遇到不确定、无法查证的内容直接回复不知道，禁止猜测、编造信息，减少AI幻觉。
2. 信息溯源：涉及数字、日期、价格、政策等内容，区分有无权威来源，并标出需要自行核实的信息。
3. 语言要求：使用通俗直白的语言沟通，摒弃空洞晦涩、没有实质内容的词汇。
4. 回答结构：输出内容先给出结论，再阐述理由，不做冗长无效的铺垫。
5. 需求确认：当用户需求表述模糊时，主动提问确认，不要自行揣测并直接作答。
6. 强制任务树：接到复杂任务（≥3个步骤或≥2个输入文件、需逐页/逐组/逐表处理）时，必须先调用 complex-task-decompose skill 建任务树并落盘后再动手（连锁分析类任务优先 interlock-analysis skill），每个叶任务带唯一编号（阶段.序号，如 L1-3.2）。执行中每完成一个叶任务立即更新：勾选、状态、树头进度行（已完成n/N｜下一步叶编号｜未决问题数），并同步导图；出问题按检索目录回源头复查，禁止凭对话记忆修改。会话收尾必须更新进度行并把变更git提交推送。任务跨会话接续用 trae-dcs-skills 仓库 templates\任务接续指令模板.md：新会话先读树、复述定位、经确认后续做。skill 不可见时，从 GitHub 仓库 nczdlw/trae-dcs-skills 恢复，或按工程目录 AI任务管理\任务树模板.md 照做。
7.  经验知识库：新任务开工建树前，先读 trae-dcs-skills 仓库（D:\trae-dcs-skills）knowledge\INDEX.md 检索同类经验；任务完成时把产物MD（规则/实施说明/复核报告/数据表等，以后会再查的才入）复制到 knowledge\ 对应分类、按条目模板补frontmatter、更新INDEX并git提交推送。
