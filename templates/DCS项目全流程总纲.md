## P1 资料搜集整理（交付物: 资料清单）

- 目标: 项目全部资料分类归档完毕，有清单可查
- 输入: 合同技术附件、成品图纸包、点号表、厂商资料（GSD/手册/选型）、邮件确认、参考项目 PDF
- 检索目录模式: 工程根目录下 `成品图-<日期>\`、`更新点号表<版本>\`、`邮件\`、`<厂商/系统名>\`（GSD、手册）
- 核对方法: 清单条目与实际文件一一对应；每类信息能指出"最新版是哪个"

- [ ] L2 建立资料清单（名称/版本/日期/位置/用途）
  - 输入: 工程根目录全部资料目录
  - 输出: `AI任务管理\资料清单.md`
  - 核对: 抽查清单中 5 项与磁盘实际文件一致
  - 状态: ⬜
  - 问题: -

## P2 基准确认（交付物: 项目基准清单）

- 目标: 每类信息锁定唯一基准，杜绝"拿旧版干活"
- 输入: 资料清单
- 检索目录模式: 同 P1
- 核对方法: 基准文件版本日期确为最新；与旧版差异已过目

- [ ] L2 建立项目基准清单（IO 基准 / 图纸版次 / 连锁 PDF / 参考用途）
  - 输入: `AI任务管理\资料清单.md`
  - 输出: `AI任务管理\项目基准清单.md`
  - 核对: 每类信息只有一个基准条目；版本日期为最新
  - 状态: ⬜
  - 问题: -

## P3 系统设计（交付物: 分组方案 + 程序结构 + HW/类型清单）

- 目标: 分组方案与程序结构定稿
- 输入: 基准清单、工艺流程分组表、BID 图纸、设备清单
- 检索目录模式: 工艺分组表 / BID 图纸目录、DP 设备清单
- 核对方法: 组覆盖全部设备无遗漏无重复；一个 FB 实例只属于一个 Program

- [ ] L2 BID 分组方案与 Program 结构方案
  - 输入: 工艺流程分组表 + BID 图纸
  - 输出: 分组方案文档（如 `3E8-2R1_BID分组方案.xlsx` + Program 结构说明）
  - 核对: 设备全覆盖、无跨程序重复实例
  - 状态: ⬜
- [ ] L2 HW 配置清单（控制器/IO/通讯/DP 从站）
  - 输入: DP 设备清单、点号表
  - 输出: HW 配置清单
  - 核对: IO 点容量与模块配置匹配
  - 状态: ⬜
- [ ] L2 自定义类型 DSD 清单（须在 Control Builder 先定义再导表）
  - 输入: 厂商通讯报文结构、GSD
  - 输出: DSD 清单
  - 核对: 每个自定义类型有定义位置记录
  - 状态: ⬜

## P4 逐组编程（交付物: 各组代码与表；**任务树主战场**）

- 目标: 每组完成 连锁分析 → VAR/FUN 表 → FBD/ST → 确认表
- 输入: 基准 PDF、IO 点号表、master 表
- 检索目录模式: 连锁图 `成品图\05-EMSR\E-Doc\07_Interlocking diagram_VP\`、启停顺序 `04_Start_Stop_Sequence_diagram\`、IO `更新点号表<版本>\`
- 核对方法: 调用 `.trae\skills\interlock-analysis` skill 的复查阶段（逐页回读 + 跨组一致性 + master 去重）

- [ ] L2 每组: 按 interlock-analysis skill 建组级任务树并逐叶执行
  - 输入: `.trae\skills\interlock-analysis\SKILL.md` + 该组基准资料
  - 输出: `AI任务管理\连锁分析-<项目名>\<组名>` 系列产物
  - 核对: 该组任务树全部叶 ✅ 后才进下一组（一组一验，逐组推进）
  - 状态: ⬜
  - 问题: -

## P5 核对复查（交付物: 核对报告）

- 目标: 全项目一致性
- 输入: 各组产物、master 表、点号表
- 检索目录模式: `AI任务管理\` 下各组产物 + 现场 Control Builder 导出目录
- 核对方法: IO 点全覆盖；变量无重名冲突；实例唯一；报警文本检查；**AI 产物加测测试化核对与 FB 实例完整性检查（方法见 interlock-analysis skill 第六/七节：测试用例反推 + EXP/ACT/MSG 断言 + 实例未调用/双调/触发器复用检查，2026-09-14 GitHub 调研新增）**

- [ ] L2 IO 点全覆盖核对（点号表 vs 程序引用）
  - 输入: 基准点号表 + 各组 VAR 表
  - 输出: IO 核对报告（未引用点 / 未定义引用）
  - 核对: 双向比对无遗漏
  - 状态: ⬜
- [ ] L2 变量与 FB 实例去重、类型冲突检查
  - 输入: 各组 VAR/FUN 表 + master 表
  - 输出: 差异与冲突清单
  - 核对: 冲突逐条有处理结论
  - 状态: ⬜
- [ ] L2 跨组连锁一致性（组间启停/联锁衔接）
  - 输入: 各组 FBD 管脚连接说明
  - 输出: 一致性结论
  - 核对: 组间信号交接无悬空
  - 状态: ⬜
- [ ] L2 测试化核对（连锁逻辑反推测试用例）
  - 输入: 各组连锁条件表 + FBD 管脚连接说明（五段式文本表示）
  - 输出: 测试用例表与断言结果（EXP/ACT/MSG 三段式，数值带容差）
  - 核对: 每条连锁条件至少 1 个用例；含边界用例；断言失败项逐条有处理结论
  - 状态: ⬜

## P6 交付（交付物: 移交清单）

- 目标: 移交现场可用的工程与资料
- 输入: 全部产物
- 检索目录模式: 现场 Control Builder 工程导出目录、`AI任务管理\`
- 核对方法: 移交清单与实物一一对应；待确认事项单独移交

- [ ] L2 导出 afw 工程并归档版本
  - 输入: Control Builder 工程
  - 输出: 导出目录（如 `最新现场 Control Builder 工程导出\`）
  - 核对: 导出文件时间戳与版本登记一致
  - 状态: ⬜
- [ ] L2 资料移交清单（含待确认事项，如莱歇待确认设定值表）
  - 输入: 全部产物 + 待莱歇确认表
  - 输出: 移交清单（签字版留档）
  - 核对: 清单条目与实物一一对应
  - 状态: ⬜
