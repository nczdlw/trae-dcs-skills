## 使用备忘

- **叶任务编号** = 阶段.序号（如 L1-3.2），全树唯一；复查区、接续指令引用叶任务一律用编号
- **叶任务准入四标准**（不满足任一条就继续拆）：单一输入源 / 单一输出物 / 可独立核对 / 上下文自足（只靠检索目录+产物就能复查）
- **颗粒度判据**：AI 拿到该叶输入后能不提问直接完成；还要问 = 拆得不够，一个编号装多件事 = 拆得太细
- **执行规则**：开工先建树 → 每轮重读树 → 完成一个叶先自检（核对判据满足？在重复劳动？下一步编号明确？）再落盘（勾选+状态+进度行+导图）→ 一次只做一个叶 → 出问题按检索目录回源头复查 → 卡叶（连续2轮无进展/重试3次）标❌升级，重拆前先写失败根因 → 执行时只改状态/问题/进度行，改输入/输出/核对=走重拆 → 任务树只由主会话写 → 会话收尾更新进度行并 git 提交 → 全部 ✅ 后收割 skill
- 详细规范见 `.trae\skills\complex-task-decompose\SKILL.md`
