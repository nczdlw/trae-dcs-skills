# ABB 800xA VAR/FUN 对比、合并与编译检查规则

## 1. 本次错误结论

编译错误：

```text
Error 1000 : Variables : The variable name N562_LQ1_T49_T_HH is not unique.
Row 240
Row 512
```

表示同一个 Program 的 VAR 表中存在两个完全相同的变量名。

- 第240行：现场 Control Builder 工程中原有变量。
- 第512行：从 G20 增量 VAR 表再次导入的变量。
- 处理：从 `CementMill_G20.VAR.xlsx` 删除 `N562_LQ1_T49_T_HH`，保留工程中的原变量。

## 2. 文件定位

- `NEW_CEMENT.VAR.xlsx`：CementMill Program 的完整 VAR 基线表。
- `NEW_CEMENT.FUN.xlsx`：CementMill Program 的完整 FUN 基线表。
- `CementMill_G20.VAR.xlsx`：仅包含 G20 需要新增的变量。
- `CementMill_G20.FUN.xlsx`：仅包含 G20 需要新增的功能块实例。

`CementMill_G20` 文件不是完整程序表，只能作为增量清单使用。

## 3. VAR 表去重规则

1. 变量名是唯一键，比较时忽略大小写并去掉名称前后的空格。
2. 对比范围必须是变量名字段，不能依靠行号、说明、数据类型或设备位号判断是否相同。
3. 只要变量在现场 Control Builder Program 中已经存在，就不得再次放入 G20 增量 VAR 表。
4. 即使变量未出现在离线导出的 `NEW_CEMENT.VAR.xlsx` 中，只要现场工程编译证明它已经存在，也按“已有变量”处理。
5. 新变量只有在以下检查全部通过后才能进入增量表：
   - 现场 Program 的 VAR 表中不存在；
   - 最新导出的完整 VAR 表中不存在；
   - 本次增量 VAR 表内部不存在重复；
   - 名称、数据类型、初始值和属性已经确认。
6. 合并后的完整 VAR 表必须保证每个变量名仅出现一次。

## 4. FUN 表去重规则

1. 功能块实例名是唯一键，比较时忽略大小写并去掉前后空格。
2. 已存在的实例不得再次放入 G20 增量 FUN 表。
3. 功能块类型变化不能通过新增同名实例完成，应修改原实例类型或在 Control Builder 中确认正确处理方式。
4. `G20` 已存在且类型为 `Group1` 时，不得在增量 FUN 表中再次新增 `G20`。
5. 合并后的完整 FUN 表必须保证每个实例名仅出现一次。

## 5. 标准工作流程

### 步骤一：确认现场完成状态

每次检查或生成增量表前，先确认：

- 哪些组程序已经完成；
- 哪些 VAR/FUN 已经在现场工程中建立；
- 功能块类型是否已经修改；
- 是否重新导出了最新工程；
- 导出文件的时间是否晚于最后一次现场修改。

### 步骤二：建立现场基线

以最新 Control Builder 工程导出的 Program VAR/FUN 表为主要基线。  
正式资料、旧导出表和设计清单用于补充核对，不能覆盖现场工程的实际状态。

### 步骤三：生成增量表

```text
G20 增量 = G20 设计所需项目 − 现场工程已有项目
```

增量 VAR/FUN 表中不得包含任何现场已有名称。

### 步骤四：更新完整表

```text
更新后的 NEW_CEMENT = 最新现场基线 + 已确认的增量
```

更新后再次执行全表唯一性检查。

### 步骤五：导入与编译

1. 先导入 VAR 增量。
2. 检查是否出现重复变量、类型不一致或初始值格式错误。
3. 再导入 FUN 增量。
4. 完成 FBD 管脚连接。
5. 编译整个 CementMill Program，而不只是检查单个 G20 图页。
6. 保存编译日志。

## 6. 编译报错处理优先级

资料冲突时按以下优先级判断：

1. 当前现场 Control Builder 工程及其编译结果；
2. 最新现场工程导出表；
3. 已确认完成状态；
4. 正式设计资料；
5. 历史导出表和工作清单。

编译结果发现已有变量时，必须立即把该变量从增量表移除，并更新去重基线。

## 7. 每次交付前检查清单

- [ ] 已确认最新现场工程导出时间。
- [ ] 已确认本次已完成和未完成的工作。
- [ ] 增量 VAR 内部无重复名称。
- [ ] 增量 FUN 内部无重复实例名。
- [ ] 增量 VAR 与现场 VAR 无交集。
- [ ] 增量 FUN 与现场 FUN 无交集。
- [ ] 完整 VAR 表全表名称唯一。
- [ ] 完整 FUN 表全表实例名唯一。
- [ ] VAR 表中没有混入 FUN 表记录。
- [ ] `G20` 功能块类型仍为 `Group1`。
- [ ] 编译整个 CementMill Program，无错误后再作为正式交付版本。

## 8. 本项目后续执行原则

今后每次生成 G20、G30、G40、G50、G55、G58 等组的增量表，都必须先取得并核对最新现场工程导出。用户确认已在 ABB 中完成的内容，立即纳入“现场已有项”，不得仅凭旧 Excel 表再次添加。


当前离线 `NEW_CEMENT.VAR.xlsx` 的全表扫描还发现若干历史重复名称，但本次现场编译没有报告这些名称。由于离线表与现场工程状态存在差异，在取得下一次最新现场 VAR 导出前，不对这些历史项做批量删除。
