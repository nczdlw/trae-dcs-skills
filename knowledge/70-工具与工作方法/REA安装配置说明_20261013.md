# REA（Reverse Engineer Anything）安装配置说明

## 一、项目是什么

- 官方仓库：<https://github.com/morluto/rea>（npm 包名 `rea-agents`，MIT）
- 定位：面向 AI Agent 的逆向工程平台，**Skill（调查指令）+ MCP server（170 个工具）**双件套
- 覆盖：PE/ELF/WASM/固件/APK 二进制、Electron/JavaScript 应用、.NET 程序集、浏览器与 Electron 运行时观测、EVM 字节码等
- 版本：6.4.0（2026-10-13 安装时的 npm latest）

## 二、本机安装结果（2026-10-13）

### 1. Skill（指令层）

| 位置 | 用途 |
|---|---|
| `C:\Users\nczdl\.workbuddy\skills\reverse-engineer-anything\` | **WorkBuddy 用户级技能目录**（本处生效） |
| `C:\Users\nczdl\.agents\skills\reverse-engineer-anything\` | REA 官方共享目录（`rea doctor --skill` 只认这里和 ~/.claude/skills） |

- 内容：SKILL.md + references/ 共 7 个文件，与 npm 包 6.4.0 内 `skills/reverse-engineer-anything/` 逐字节一致
- `rea doctor --skill --json` 结果：`skill:identity = aligned`（健康）

### 2. MCP server（工具层）

`C:\Users\nczdl\.workbuddy\mcp.json` 中新增条目（与 cad-mcp、autocad-draft 并列）：

```json
"rea": {
  "command": "cmd",
  "args": ["/d", "/c", "C:\\Program Files\\nodejs\\npx.cmd", "-y", "rea-agents@6.4.0", "mcp"],
  "disabled": false
}
```

要点：

- 该形状来自 REA 官方文档的 MCP Registry 条目（`command: npx` + `args: ["-y","rea-agents@<版本>","mcp"]`），Windows 上按官方约定用 `cmd /d /c` 包裹（官方 setup 在 Windows 也是这样写的）
- 用**绝对路径** `C:\Program Files\nodejs\npx.cmd` 而非裸 `npx`，避免 MCP 派生进程 PATH 不稳
- 版本必须钉死 exact version（官方要求）：当前 `6.4.0`
- **改完 mcp.json 不会自动生效**：需在 WorkBuddy 自定义连接器页面对 `rea` 点"信任"，再重开会话

### 3. 握手验证（2026-10-13 实测）

- `initialize` → `serverInfo: {"name":"rea","version":"6.4.0"}`，约 9.4s（含 npx 冷缓存）
- `tools/list` → **170 个工具**（与 SKILL.md 里 `tool_count: 170` 一致）
- Node 要求：22.x(≥22.19)/24.x(≥24.11)/26+。本机满足：managed Node 22.22.2、系统 Node 24.14.0（`C:\Program Files\nodejs`）

## 三、WorkBuddy 不在官方支持列表的处理

REA `setup` 只认它自己的客户端（Claude Code/Codex/Cursor/Gemini CLI/Trae 等 21 个），**没有 WorkBuddy**，所以：

- 不要跑 `npx rea-agents setup`（交互式，且会往其他客户端配置里写东西）
- 按上面第 2 节手动注册 MCP + 手动拷 skill 即可，功能等价
- `rea doctor`（审计模式）会报其他客户端的 registration config_drift 和 skill "stale"——这是因为它按那些客户端的技能目录逐一比对，**与 WorkBuddy 侧安装无关**；以 `rea doctor --skill --json`（exit 0、aligned）为准

## 四、可选分析引擎（按需，未安装）

深度原生二进制分析才需要，静态 JS/.NET/APK 分析不需要：

| 引擎 | 配置方式 |
|---|---|
| Hopper | 商业软件；`rea setup` 经批准后可装，或设 `HOPPER_LAUNCHER_PATH` |
| Ghidra | 需自装 12.1.x + JDK 21，设 `GHIDRA_INSTALL_DIR`（REA 从不代装 Java/Ghidra） |
| IDA | 复用 mrexodia/ida-pro-mcp，设 `REA_IDA_MCP_CONFIG` |

## 五、升级方法

```bash
npm view rea-agents dist-tags.latest          # 查最新版
# 1) 更新 MCP 注册：编辑 mcp.json 把 args 里的版本号改成新版本，再点"信任"
# 2) 更新 skill：重新 npm pack 解压，拷贝 skills/reverse-engineer-anything/ 覆盖两个技能目录
# 3) 验证：npx -y rea-agents@<新版本> doctor --skill --json
```

## 六、使用入口

装好后在 WorkBuddy 会话里直接说需求即可（skill 会自动匹配），例如："逆向这个 Electron 应用"、"分析这个 APK"、"看看这个 exe 里有什么"。MCP 工具需在连接器页信任后、重开会话才可见。
