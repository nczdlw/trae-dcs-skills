# GitHub电气自动化编程项目调研报告（8项目深入研究）

> 调研目的：在 GitHub 搜集电气自动化编程相关项目，研究后补充/完善本仓库（trae-dcs-skills）的规则和技能。
> 方法：4方向关键词检索（GitHub API，star降序）→ 按筛选标准（相关性/star≥30或独特价值/活跃度/质量）选出8重点项目 → 3个并行研究子代理逐仓库研读README/目录/关键源文件 → 提炼改进点 → 实施。
> 完整研究笔记见 `AI任务管理/GitHub电气自动化项目调研与技能完善/调研-重点项目研究.md`（含全部文件级来源引用）。

## 0. 检索总览与关键结论

| 方向 | 结果 |
|------|------|
| A. PLC/IEC 61131-3框架规范 | 丰富：trust-platform(220★)/iec-checker(107★)/OOP示例/状态机FB等 |
| B. 自动化标准库与实践 | OSCAT系列/4diac(IEC 61499)/TcUnit(417★)/arduino_plclib |
| C. AI辅助工业编程 | **价值最高**：hkoziolek系列（Kiel大学）/twincat-agent/plc-st-review/多个MCP桥 |
| D. ABB 800xA/DCS/水泥 | **几乎为零**：专有DCS生态不开源，无可借鉴项目（如实记录） |

结论：专有DCS（800xA）无开源实践可抄，价值全部从 IEC 61131-3 通用实践 + AI辅助工程化两条线迁移。
