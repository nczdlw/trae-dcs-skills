# AutoCAD MCP 服务器安装配置说明

## 一、本机环境事实

- 已装 **AutoCAD 2026 - 简体中文**，注册表版本键 `HKLM:\SOFTWARE\Autodesk\AutoCAD\R25.1`。
- 可用工具链：
  - git：`C:\Program Files\Git\bin\git.exe`（注意：不是 PortableGit 那个路径）
  - uv：`C:\Users\nczdl\.local\bin\uv.exe`
  - Python 3.13.12（managed）：`C:\Users\nczdl\.workbuddy\binaries\python\versions\3.13.12\python.exe`
  - 系统 Python 3.12.10：`C:\Users\nczdl\AppData\Local\Programs\Python\Python312\python.exe`
- MCP 配置文件位置：`C:\Users\nczdl\.workbuddy\mcp.json`（**不是**带点的 `.mcp.json`）

## 二、已安装的两个服务

### 1. cad-mcp（daobataotie/CAD-MCP v2.0，MIT）

- 源码：`C:\Users\nczdl\mcp-servers\CAD-MCP-daobataotie`
- 解释器：`C:\Users\nczdl\mcp-servers\CAD-MCP-daobataotie\.venv\Scripts\python.exe`
- 启动入口：`src\server.py`
- 依赖：mcp 1.30.0 / pywin32 312 / pydantic 2.13.5 / Pillow 12.3.0
- 控制方式：**Windows COM**（pywin32 → AutoCAD ActiveX），35 个细粒度工具（draw_line / list_entities / send_command 等）
- 使用前提：AutoCAD 进程已启动（Server 会自动尝试拉起）
- 已改动：`src\config.json` 中 `output.directory` 由相对路径 `./output` 改为绝对路径
  `C:\Users\nczdl\mcp-servers\CAD-MCP-daobataotie\output`。
  **原因**：代码里是 `os.path.join(config["output"]["directory"], ...)`，依赖进程 cwd，
  MCP 客户端启动时的 cwd 不受控，不改成绝对路径会出现图纸存到未知地点。

### 2. autocad-draft（puran-water/autocad-mcp v3.1，MIT）

- 源码：`C:\Users\nczdl\mcp-servers\autocad-mcp-puran`
- 解释器：`C:\Users\nczdl\mcp-servers\autocad-mcp-puran\.venv\Scripts\python.exe`（uv ven系 Python 3.12.10）
- 启动方式：`python -m autocad_mcp`（uv sync 已做 editable install，与工作目录无关）
- 依赖：ezdxf 1.4.3 / pillow 12.1.1 / matplotlib 3.10.8 / pywin32 311 / mcp 1.26.0 / structlog
- 控制方式：**File IPC**（`C:\temp\*.json`）+ AutoCAD 侧 LISP 派发器，8 个聚合工具
  （drawing / entity / layer / block / annotation / pid / view / system）
- 双后端：`AUTOCAD_MCP_BACKEND=auto`，有 AutoCAD 走 file_ipc，没 AutoCAD 自动降级 ezdxf 无头生成 DXF
- **必须手动做的一步**：在 AutoCAD 里 `APPLOAD` 加载
  `C:\Users\nczdl\mcp-servers\autocad-mcp-puran\lisp-code\mcp_dispatch.lsp`，
  命令行出现 `=== MCP Dispatch v3.1 loaded ===` 才算就绪。建议加进"启动套件"自动加载。
- IPC 目录 `C:\temp` 已创建。改目录要同步改 lisp 里的 `*mcp-ipc-dir*`，两边必须一致。

## 六、坑

1. WorkBuddy 自带 Bash 的 PATH 不稳定，`ls` / `cat` / `tr` / `head` 等 coreutils 时有时无；
   `git.exe` 也不在默认路径里。**做法：一律用 Python 的 subprocess 驱动外部命令**。
2. PowerShell 工具执行后 stdout 常常不返回内容。**做法：让脚本把结果写文件，再用 Python 读文件**。
3. 装完后 MCP **不会自动生效**，要在 WorkBuddy 自定义连接器管理页对新增服务点"信任"。
4. 两个服务可以同时连，但都操作同一个 AutoCAD 实例：一个走 COM SendCommand，一个走 PostMessage 派发 LISP，
   **不要同时并发下命令**，容易互相打断。日常用 cad-mcp 画/改/查，autocad-draft 用来无头批量出 DXF。
