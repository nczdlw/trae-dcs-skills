## 缩写与连锁类型说明

| 缩写 | 全称 | 说明 |
|------|------|------|
| STAITL | Start Interlock | 启动连锁（条件不满足则无法启动） |
| OPITL | Operation Interlock | 操作连锁（条件不满足则停止运行） |
| PRTITL | Protection Interlock | 保护连锁（触发后停止设备） |
| PSTITL | Protective Start Interlock | 保护性启动连锁（保护条件不满足则无法启动） |
| STPITL | Stop Interlock | 停止连锁 |
| PHYFB | Physical Feedback | 物理反馈 |
| AVBL | Available | 可用信号 |
| RUN | Running | 运行反馈 |
| ON | On | 开启 |
| OFF | Off | 关闭 |
| PQSTOP | Process Quick Stop | 过程快速停止 |
| ITL | Interlock | 连锁 |
| TON | Timer On-Delay | 通电延时（条件满足后延时输出） |
| TOF | Timer Off-Delay | 断电延时（条件消失后延时复位） |
| SR | Set-Reset Flip-Flop | 置位/复位触发器 |
| NS | Non-Stored (output) | 非存储型输出（脉冲） |
| S | Stored (output) | 存储型输出（锁存） |

### 信号阈值等级

| 等级 | 含义 | [参考] 对应 |
|------|------|-------------|
| H4 | 最高高报警 | — |
| H3 | 高3报警 | — |
| H2 | 高2报警（通常触发保护停止） | max2 (报警/停机级) |
| H1 | 高1报警（通常触发警告/启动连锁） | max1 (警告级) |
| L1 | 低1报警 | min (最低运行值) |
| L2 | 低2报警（通常触发保护停止） | min2 (报警级) |
| L3 | 低3报警 | min1 (警告级) |
| L4 | 最低低报警 | — |
| LL | 极低 | — |
| HH | 极高 | — |

### [参考] 阈值命名对照

| 参考项目阈值 | 本项目对应 | 说明 |
|-------------|-----------|------|
| max1 | H1 | 警告级（较高阈值的第一级） |
| max2 | H2 | 报警级（较高阈值的第二级，触发停机） |
| min1 | L1 / L3 | 警告级（较低阈值） |
| min2 | L2 | 报警级（较低阈值，触发停机） |
| SP1 | — | 设定值1（加热器启动/润滑释放阈值） |
| SP2 | — | 设定值2（加热器开启阈值） |
| SP3 | — | 设定值3（加热器关闭阈值） |

## 1. 齿轮箱润滑系统 (MGL/MGB)

**标签前缀**：1632LQ01, 1632GB01
**图纸页码**：p102-145 [参考: 本系统在参考项目中归入减速机润滑站，信号包含在磨主电机联锁0302页中]

### 1.1 信号标签清单

| 信号标签 | 描述 |
|----------|------|
| 1632LQ01.LS01 | 齿轮箱油箱液位 (Oil tank level) |
| 1632LQ01.TI01 | 齿轮箱油箱温度 (Oil tank temperature) |
| 1632LQ01.PI01 | 低压油路压力 (LP oil pressure) |
| 1632LQ01.PDI01 | 过滤器差压 (Filter differential pressure) |
| 1632LQ01.MT01 | 油泵电机1 (Oil pump motor 1) |
| 1632LQ01.MT02 | 油泵电机2 (Oil pump motor 2) |
| 1632LQ01.MT03 | 盘车电机 (Inching drive motor) |
| 1632LQ01.HE01 | 油箱加热器 (Oil tank heater) |
| 1632GB01.PI01~PI12 | 12个可倾瓦高压油压力 (Tilting pad 1-12 HP pressure) |
| 1632GB01.TS01~TS10 | 滑动轴承温度1-10 (Slide bearing temperature 1-10) |
| 1632GB01.FS02 | 到可倾瓦油流量 (Oil flow to tilting pads) |
| 1632GB01.PS01 | 油流压力开关 (Oil flow pressure switch) |
| 1632GB01.TS80 | 盘车机构温度 (Inching drive temperature) |

### 1.2 组级连锁信号

| 组级信号 | 描述 |
|----------|------|
| 1632LQ01:GR_STAITL | MGB组启动连锁 |
| 1632LQ01:GR_OPITL | MGB组操作连锁 |
| 1632LQ01:MGB_PSTITL | MGB保护性启动连锁 |
| 1632LQ01:MGB_PRTITL | MGB保护连锁 |
| 1632LQ01:MD_PSTITL | 磨机驱动保护性启动连锁 |
| 1632LQ01:MD_PRTITL | 磨机驱动保护连锁 |
| 1632LQ01:GB_INCH_AVBL | 盘车机构可用 |
| 1632LQ01:GB_INCH_ON | 盘车机构运行中 |

### 1.3 油箱监测与报警

**油箱液位 (1632LQ01.LS01)**：
- `> LL`：油箱液位 > 极低 → 组启动连锁条件
- `< L2`：油箱液位 < 低2 → 报警

**油箱温度 (1632LQ01.TI01)**：
- `> H1`：油箱温度 > 高1 → 警告
- `> H2`：油箱温度 > 高2 → 保护停止
- `< L1`：油箱温度 < 低1 → 加热器启动 / 组启动连锁
- `< L2`：油箱温度 < 低2 → 保护停止
- 加热器逻辑：`1632LQ01.TI01 < L1` AND `16xx:HEATER_ENABLED` → `1632LQ01.HE01:ON`（延时5秒）

**低压油压力 (1632LQ01.PI01)**：
- `< L2`：低压油压力 < 低2 → MGB保护连锁 / 磨机驱动保护连锁

**过滤器差压 (1632LQ01.PDI01)**：
- `> H1`：过滤器差压 > 高1 → 过滤器堵塞警告

### 1.4 油泵电机连锁

**油泵电机1 (1632LQ01.MT01) / 油泵电机2 (1632LQ01.MT02)**：
- 启动连锁 (STAITL)：
  - `1632LQ01.LS01 > LL`（油箱液位 > 极低）
  - `1632LQ01.TI01 > L1`（油箱温度 > 低1）
  - NOT `1632LQ01.MT03:RUN`（盘车电机未运行）
- 保护性启动连锁 (PSTITL)：
  - `1632LQ01.PI01 < L2`（低压油压力 < 低2，延时3 min）
  - `1632GB01.PS01`（油流压力开关）
  - `1632GB01.FS02`（油流量 LL）
- 运行反馈延时：油泵启动后延时2 min确认运行 (`RUN_DELAYED_DRIVE`)
- 油泵切换运行时间监控 (`T_EX_RUN`)：超过设定运行时间后切换备用泵

### 1.5 可倾瓦高压压力监测 (1632GB01.PI01~PI12)

12个可倾瓦（Tilting pad 1-12）各有独立压力监测：

**每个瓦的压力信号**（以PI01为例，PI02~PI12相同模式）：
- `1632GB01.PI01`：实时压力值
- 阈值等级：H4 / H3 / H2 / H1 / L1 / L2 / L3 / L4
- `> H2`：压力 > 高2 → HMI报警
- `< SL1`：压力 < 开关限1 → 报警
- `< L2`：压力 < 低2 → HMI报警

**HP保护连锁 (1632GB01:PRTITL)**：
- 逻辑：12个瓦中任意一个 `PIxx < L2`（延时TON）→ 触发HP保护
- 保护组合：`1632GB01.PI01:<L2` OR `1632GB01.PI02:<L2` OR ... OR `1632GB01.PI12:<L2` → 延时 → PRTITL

### 1.6 滑动轴承温度监测 (1632GB01.TS01~TS10)

10个滑动轴承温度测点：
- `> H1`：温度 > 高1 → 警告
- `> H2`：温度 > 高2 → 保护停止
- 保护组合：任意 `TSxx > H2` → PRTITL

### 1.7 MGB保护性启动连锁 (for mill drive) — 1632LQ01:MD_PSTITL

**逻辑**（AND关系）：
1. `1632LQ01.PI01 < L2`（低压油压力 < 低2）— 延时3 min
2. `1632GB01.PS01`（油流压力开关触发）
3. `1632GB01.FS02`（油流量 LL）
4. `1632GB01.FS02:NOT_RUN_DELAYED`（油流量未运行延时）

→ 输出到磨机主电机保护性启动连锁 `1632MD01.MT01:PSTITL`

### 1.8 MGB保护连锁 (for mill drive) — 1632LQ01:MD_PRTITL

**逻辑**（OR关系）：
1. `1632LQ01.PI01 < L2`（低压油压力 < 低2）
2. `1632GB01.FS02`（油流量 LL）
3. `1632GB01.PS01`（油流压力开关）

→ 输出到磨机主电机保护连锁 `1632MD01.MT01:PRTITL` → 触发PQSTOP

### 1.9 盘车机构 (Inching Drive)

**盘车电机 (1632LQ01.MT03)**：
- 启动连锁 (STAITL)：
  - `1632LQ01.MT01:RUN` OR `1632LQ01.MT02:RUN`（至少一台油泵运行）
  - `1632LQ01.PI01 >= L2`（低压油压力 >= 低2）
  - `1632HS11:ARE_RAISED`（HSLM辊子已提升）
  - `1632HS21:ARE_RAISED`（HSSW辊子已提升）
  - NOT `1632MD01.MT01:RUN`（主电机未运行）
- 盘车运行时锁定主电机启动
- `1632GB01.TS80 < HH`：盘车机构温度 < 极高

### 1.10 MGB组启动连锁 — 1632LQ01:GR_STAITL

**逻辑**（AND关系）：
1. `1632LQ01.LS01 > LL`（油箱液位 > 极低）
2. `1632LQ01.TI01 > L1`（油箱温度 > 低1）
3. `1632LQ01.MT01:AVBL` OR `1632LQ01.MT02:AVBL`（至少一台油泵可用）
4. `1632LQ01.PI01 >= L2`（低压油压力达到，由泵启动后建立）

### 1.11 MGB组操作连锁 — 1632LQ01:GR_OPITL

**逻辑**（OR关系）：
1. `1632LQ01.PI01 < L2`（低压油压力 < 低2，延时）
2. `1632GB01.FS02`（油流量 LL）
3. `1632GB01.PS01`（油流压力开关）
4. `1632LQ01.TI01 > H2`（油箱温度 > 高2）
5. HP监测保护（任意可倾瓦压力 < L2）

### [参考] 1.12 减速机在磨主电机联锁中的角色

[参考] 在GXBeiliu项目图0302中，减速机润滑站参与磨主电机联锁的条件：
- 减速机油站允许磨机远程起动（Mill Start Released）
- 减速机本体和油站无报警（Gearbox monitoring 2）
- 减速机润滑站运行
- 减速机润滑站无故障
- 减速机本体和润滑站无故障（监测1）
- 辅传链条位置检测（NC常闭，链条在位时闭合）
- 辅传电机运行（NC常闭，电机未运行时闭合）

**图纸页码**：p157-186 [参考: 图号1601-1625]

### 2.1 信号标签清单

| 信号标签 | 描述 | [参考] 图号 |
|----------|------|-------------|
| 1632HS11.TI01 | 液压油箱温度 (Oil tank temperature) | 1260 |
| 1632HS11.LS01 | 液压油箱液位 (Oil tank level) | 1203 |
| 1632HS11.PI01 | 工作压力 (Working pressure, WP) | 1605 |

### 2.2 组级连锁信号

| 组级信号 | 描述 |
|----------|------|
| 1632HS11:GR_STAITL | HSLM-S 1.A组启动连锁 |
| 1632HS11:GR_OPITL | HSLM-S 1.A组操作连锁 |
| 1632HS11:ARE_RAISED | 辊子已提升 (Rollers are raised) |
| 1632HS11:KEEP_RAISED | 保持辊子提升 (Keep rollers raised) |
| 1632HS11:GRIND | 研磨模式 (Grinding mode) |
| 1632HS11:RAISE | 提升辊子 (Raise rollers) |

### 2.3 油箱监测

**油箱温度 (1632HS11.TI01)**：
- `> H1`：温度 > 高1 → 警告
- `> H2`：温度 > 高2 → 组操作连锁
- `< L1`：温度 < 低1 → 加热器启动 / 组启动连锁
- 加热器：`1632HS11.TI01 < L1` AND `16xx:HEATER_ENABLED` → `1632HS11.HE01:ON`（延时5秒）

**油箱液位 (1632HS11.LS01)**：
- `> LL`：液位 > 极低 → 组操作连锁

### 2.4 压力监测

**工作压力 (1632HS11.PI01)**：
- `> P_MAX_DELAYED`：工作压力 > 最大值（延时）→ 组操作连锁
- `< P_MIN_DELAYED`：工作压力 < 最小值（延时）→ 组操作连锁 / 磨机主电机保护连锁
- `> P_R`：工作压力 > 提升压力阈值 → 保持辊子提升

**反压力 (1632HS11.PI02)**：
- `> P_MAX_DELAYED`：反压力 > 最大值（延时）→ 组操作连锁
- `< P_MIN_DELAYED`：反压力 < 最小值（延时）→ 组操作连锁
- `> WP_R`：反压力 > 提升工作压力 → 保持辊子提升

### 2.5 HSLM组启动连锁 — 1632HS11:GR_STAITL

**逻辑**（AND关系）：
1. `1632HS11.TI01 > L1`（油箱温度 > 低1）
2. NOT `1632HS11.TI01 > H1`（油箱温度未超过高1）
3. `1632HS11.MT01:AVBL`（油泵1可用）
4. `1632HS11.MT02:AVBL`（油泵2可用）

### 2.6 HSLM组操作连锁 — 1632HS11:GR_OPITL

**逻辑**（OR关系）：
1. `1632HS11.PI01 > P_MAX_DELAYED`（工作压力太高延时）
2. `1632HS11.PI01 < P_MIN_DELAYED`（工作压力太低延时）
3. `1632HS11.PI02 > P_MAX_DELAYED`（反压力太高延时）
4. `1632HS11.PI02 < P_MIN_DELAYED`（反压力太低延时）
5. `1632HS11.TI01 > H2`（油箱温度 > 高2）
6. `1632HS11.LS01 > LL`（油箱液位 > 极低触发）
7. `1632HS11.MT01:T_EX_INC_WP`（泵运行时间超限-增压时）
8. `1632HS11.MT01:T_EX_RAISE`（泵运行时间超限-提升时）
9. `1632HS11:T_EX_LOWER`（操作时间超限-降辊）
10. `1632HS11:T_EX_INC_CP`（操作时间超限-增反压）
11. `1632HS11.MT01:T_EX_RUN`（泵总运行时间超限）

### 2.7 辊子位置逻辑

**提升辊子 (1632HS11:RAISE)**：
- 条件（AND）：
  - `1632HS10:ENABLED`（组已使能）
  - NOT `1632HS10:LOCAL`（非本地模式）OR `1632HS10:LOCAL`（本地模式推按钮）
  - `1632HS11.PI01 > P_MAX_DELAYED`（工作压力太高延时）→ 停止提升
  - `1632HS11:START_WP_DONE`（起始WP调整完成）
  - `1632HS11:KEEP_RAISED`（保持提升）

**辊子已提升 (1632HS11:ARE_RAISED)**：
- 条件：
  - `1632HS11.PI01 > P_R`（工作压力 > 提升压力）AND
  - `1632HS10:ENABLED` AND `1632HS11:PARK` OR `1632HS11:KEEP_RAISED`
- 输出到：
  - `1632MD01.MT01:PSTITL`（磨机主电机保护性启动连锁-允许启动）
  - `1632LQ01`（MGB盘车机构-允许盘车）
  - `1632RM01`（磨机监控）
  - `1632HS11:GRIND`（研磨模式）

**研磨模式 (1632HS11:GRIND)**：
- `1632HS11:ARE_RAISED` AND `1632RM01.GI11:IS_RAISED` AND `1632RM01.GI21:IS_RAISED`
- 输出到磨机润滑脂系统 `1632LQ45.MT01`

### 2.8 油泵电机连锁

**油泵电机 (1632HS11.MT01 / MT02)**：
- 启动连锁 (STAITL)：
  - `1632HS11.LS01 > LL`（油箱液位 > 极低）
  - `1632HS11.TI01 > L1`（油箱温度 > 低1）
- 运行时间监控：超过设定运行时间 (`T_EX_RUN`) → 切换备用泵
- 运行模式：增压 (INC_WP)、提升 (RAISE)、降辊 (LOWER)、增反压 (INC_CP)

### [参考] 2.9 HSLM远程备妥逻辑 (图号1601)

[参考] HSLM远程备妥 (Ready for remote operation) 的9个故障条件（OR关系，任一触发则干扰）：

| 序号 | 故障条件 | 说明 |
|------|---------|------|
| 1 | 油温 > max2 | 油箱温度超过报警级 |
| 2 | 油位 < min | 油箱液位低于最低值 |
| 3 | 工作压力太低 (WP < P_MIN) | 工作压力低于最小值 |
| 4 | 反压力太低 (CP < P_MIN) | 反压力低于最小值 |
| 5 | 油泵未运行 | 泵停止 |
| 6 | VFD故障 | 变频器异常 |
| 7 | 压力确认失败 | 5s TON后压力未确认 |
| 8 | 系统急停 | 急停触发 |
| 9 | 外部干扰 | 其他系统连锁 |

- VFD/压力确认延时：**TON 5秒**
- 远程备妥 = NOT(干扰条件) AND 远程操作模式

### [参考] 2.10 辊子位置监测 (图号1602/1603)

[参考] 位置监测采用压力间接判断（无独立位置传感器时的方案）：

| 状态 | 判断条件 | 说明 |
|------|---------|------|
| 辊子已提升 (Raised) | P ≥ max | 压力达到最大值 |
| 辊子未提升 (Below raised) | P ≤ max - dP | 压力低于最大值减迟滞量 |

### [参考] 6.4 振动监测详细逻辑 (图号0305)

[参考] 振动监测采用静态+动态双重判断：

| 监测模式 | 阈值 | 延时/条件 | 动作 |
|---------|------|----------|------|
| MAX1 立即报警 | MAX1 | 无延时 | 报警 |
| MAX2 静态监测 | MAX2 | **TON 3秒** (t1) | 报警 + 磨机跳停 |
| MAX2 动态监测 | MAX2 | **60秒窗口** (t2) 内 **>3个脉冲** | 报警 + 磨机跳停 |

测量范围：**0-50 mm/s**

动态监测逻辑：
- 60秒时间窗口内，振动超过MAX2的脉冲数 > 3 → 触发跳停
- 60秒后脉冲数 < 4 → 自动复位计数器
- 静态和动态两种路径独立触发跳停（2oo2方式）

### E.3 编程建议

1. **压力阈值**：参考项目的Pmin=50bar, dp=1.5bar等值需根据本项目实际工艺设定，不可直接照搬

3. **振动监测**：参考项目的静态+动态双重监测逻辑可增强本项目振动保护的可靠性
4. **HSSW控制模式**：参考项目的速度/位置控制双模式应根据本项目实际配置选择
5. **油脂循环**：参考项目的T1/T2具体值需按机械规格书最终确认
6. **HSLM位置监测**：本项目有独立位置传感器(GI01)，可直接使用位置值；参考项目的压力间接判断方案作为备用
7. **辅机启动AND条件**：参考项目图0303的12项AND条件清单应作为磨主电机启动连锁的完整检查表
