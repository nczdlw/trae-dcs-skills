# 变频器功能块逻辑说明

> 项目：越南 F163 粉磨站 800XA 编程
> 适用功能块：`ABB_LV_VVVF`（低压，FPBA-01）、`ABB_MV_VVVF`（中压，RPBA-01）
> 平台：ABB 800XA V6.1.0，语言 ST（结构化文本）
> 编制日期：2026-07-16

本文用通俗语言说明两个变频器功能块实现的控制过程。除非特别注明，以下逻辑对 LV 与 MV 通用；两者差异在对应章节单独标注。

---

## 1. 总体思路

功能块的作用是充当 DCS 与变频器之间的"翻译官"和"管家"：

- **向下**：把 DCS 操作员的启停、调速命令，按 ABB 驱动行规组装成控制字（CW）和频率给定（REF1），通过 PROFIBUS DP 写进变频器；
- **向上**：把变频器回传的状态字（SW）和实际值（频率、电流、功率、温度等）拆解、换算成工程单位，呈现给 DCS 画面；
- **横向**：在本地完成联锁保护、运行监控、故障捕获、报警与事件记录，保证变频器按工艺要求安全运行。

整个功能块围绕一个核心布尔量 `drive`（驱动命令）运转：`drive=1` 表示"让变频器运行"，`drive=0` 表示"让变频器停止"。控制字的每一位、给定值的有无、运行监控的启停，都由 `drive` 牵头。

---

## 2. 启动逻辑

启动不是按一下按钮就完事，而是要凑齐一组条件，全部满足后才允许"开车"。

### 2.1 启动条件（LV）

```
ALLOW_START = Group_start AND Start_lock AND start_lock_en
              AND INBOOL1_B0(RDY_ON) AND INBOOL1_B1(RDY_RUN)
```

用大白话说，要同时满足五件事：

1. **组启动**（`Group_start`）：来自上位机组启动命令，确认这一组设备该启动了；
2. **启动联锁**（`Start_lock`）：启动联锁条件允许（比如前置设备已运行、阀门已就位）；
3. **启动联锁使能**（`start_lock_en`）：启动联锁功能本身处于使能状态（见 2.3，启动后会自锁断开，防止重复启动）；
4. **准备合闸**（`INBOOL1_B0`，RDY_ON）：变频器自己说"我准备好合闸了"；
5. **准备操作**（`INBOOL1_B1`，RDY_RUN）：变频器说"我准备好操作了"。

### 2.2 启动条件（MV）

MV 的启动条件多了两个外部信号、换了一个内部信号：

```
ALLOW_START = Group_start AND Start_lock AND start_lock_en
              AND READY1 AND INBOOL1_B0(RDY_ON) AND NOT INBOOL1_B6(SWC_ON_INHIB)
```

与 LV 的区别：

- 增加 **就绪信号 1**（`READY1`）：外部工艺就绪信号（如冷却水、润滑油就绪）；
- 把"准备操作（B1）"换成"**非禁止合闸（NOT B6）**"：中压变频器更看重是否处于禁止合闸状态，禁止合闸时绝不允许启动。

### 2.3 RS 触发器锁存启动命令

启动条件满足后，并不是直接输出给变频器，而是先送进一个 **RS 触发器**（`RS_1`）锁存：

```
RS_1.Set  := ALLOW_START      （置位：满足全部启动条件）
RS_1.R1   := 停止条件（见第 3 节）
drive     := RS_1.Q1          （输出：驱动命令）
```

这样设计的好处是：启动脉冲（组启动通常是短脉冲）过去后，`drive` 仍能保持为 1，变频器持续运行，直到出现停止条件才复位。这就是"按一下启动，一直运行，直到主动停或出故障"的经典自保持电路。

启动联锁使能 `start_lock_en` 的自锁逻辑也在这里起作用：

```
start_lock_en := NOT (Start_lock AND start_lock_en)
```

其含义是：一旦启动联锁条件满足且使能，`start_lock_en` 就被自锁断开，避免在运行中因启动联锁信号抖动而误判，也防止停机后未经确认就再次自动启动。

---

## 3. 停止逻辑

停止比启动"容易"得多——只要以下任何一个条件成立，RS 触发器就被复位，`drive` 变 0：

```
RS_1.R1 := Single_stop OR EMG_stop OR Ext_fault
           OR NOT process_lock OR NOT safe_lock
```

五个停止来源，按严重程度从轻到重：

| 停止来源 | 变量 | 含义 | 停车方式 |
|----------|------|------|----------|
| 单台停止 | `Single_stop` | 操作员在画面点"停止"按钮 | 斜坡停车（OFF1） |
| 急停 | `EMG_stop` | 急停按钮或安全回路触发 | 快速停车（OFF3），MV 经延时 |
| 外部故障 | `Ext_fault` | 外部设备送来的故障信号 | 斜坡停车（OFF1） |
| 工艺联锁断 | `NOT process_lock` | 工艺联锁条件丢失 | 斜坡停车（OFF1） |
| 安全联锁断 | `NOT safe_lock` | 安全联锁条件丢失 | 斜坡停车（OFF1） |

停车方式对应控制字：`drive=0` 使 CW 的 bit0（OFF1）变 0，变频器按斜坡减速停车；急停时 CW 的 bit2（OFF3）变 0，变频器快速停车。

---

## 4. 联锁逻辑

功能块有三套联锁，分工明确：

### 4.1 工艺联锁（`process_lock`）

来自工艺过程的联锁条件，例如"上游料仓料位够不够""下游皮带是否在跑"。`process_lock=1` 表示工艺允许运行，`=0` 则触发停止。它直接进入停止条件 `NOT process_lock`。

### 4.2 安全联锁（`safe_lock`）

来自安全系统的联锁条件，优先级高于工艺联锁。`safe_lock=1` 表示安全允许运行。安全联锁断开时同样触发停止。

安全联锁还配了一个 **断电延时定时器** `TOf_3`（`safe_lock_time`）：

```
TOf_3.In := safe_lock AND safe_lock_en
TOf_3.PT := safe_lock_time
```

作用是：安全联锁信号短暂抖动（瞬间断开又恢复）时，延时一定时间才真正判定为联锁断开，避免误停。`safe_lock_en` 是安全联锁使能开关。

### 4.3 启动联锁（`Start_lock`）

只在启动阶段起作用的联锁，用来保证"启动时机正确"。它进入启动条件，并在启动成功后通过 `start_lock_en` 自锁断开（见 2.3），运行期间不再约束停机。这样既保证了启动顺序，又不会在运行中因启动条件变化而误停。

### 4.4 联锁释放与锁定状态

```
UNLOCK  := process_lock AND safe_lock      （联锁全部释放，允许操作）
LOCKED  := NOT UNLOCK AND INBOOL1_B0       （未释放且变频器准备合闸 → 处于锁定状态）
```

`UNLOCK` 用于事件记录（联锁释放事件），`LOCKED` 用于画面指示当前是否被联锁锁住。

## 5. 运行监控

启动命令发出后，变频器到底有没有真正转起来？功能块用 **通电延时定时器** `TOn_3`（`run_time`）来确认：

```
TOn_3.In := drive AND INBOOL1_B2(RDY_REF)   （驱动命令 AND 允许运行）
TOn_3.PT := run_time
```

含义：`drive=1` 后，若变频器在 `run_time` 时间内回送"允许运行"（SW 的 bit2=RDY_REF=1）并持续，则认为运行正常；若超时仍未达到允许运行状态，`TOn_3.Q` 置位，触发故障。

故障锁存：

```
SR_1.S1   := TOn_3.Q          （运行超时 → 置位故障）
SR_1.Reset:= Reset            （复位按钮清除故障）
FAULT_G   := SR_1.Q1 OR INBOOL1_B3(TRIPPED)
```

`FAULT_G`（综合故障）= 启动超时故障 **或** 变频器自己报的跳闸故障（SW bit3）。故障一旦发生就锁存，必须按复位按钮 `Reset` 才能清除。

## 6. 状态机时序

ABB 变频器的启停遵循 PROFIdrive/ABB Drives 状态机，分步推进。功能块通过控制字（CW）的几位配合一个 500ms 延时，把状态机一步步走完：

```
步骤1  CW = 0x047E (bit0=0, bit1~6=1, bit10=1)
       └─ 变频器进入"准备合闸" → SW bit0 (RDY_ON) = 1

步骤2  CW = 0x047F (bit0=1, bit1~6=1, bit10=1)   ← drive=1 使 bit0 置 1
       └─ 变频器进入"准备操作" → SW bit1 (RDY_RUN) = 1

步骤3  等待 500ms（TOn_1 延时）                     ← drive=1 触发 TOn_1
       └─ 给状态机留出转换时间

步骤4  CW bit3 (OPERATION_ENABLE) = 1              ← TOn_1.Q 置位
       └─ CW 变为 0x047F | 0x0008 = 0x047F（bit3 已含在运行字中）
       └─ 变频器进入"允许运行" → SW bit2 (RDY_REF) = 1

步骤5  变频器达到给定转速 → SW bit8 (AT_SETPOINT) = 1 → RUNNING = 1
```

关键点：

- **bit3 不能一上来就给**：刚启动时直接置 bit3=1，变频器状态机可能跳步失败。所以功能块用 `TOn_1`（`T500ms`/`t500ms`）延时 500ms，让变频器先完成"准备合闸→准备操作"的转换，再使能运行（bit3=1），稳态可靠。
- **bit0 由 `drive` 控制**：`drive=1` 时 CW=0x047F（运行），`drive=0` 时 CW=0x047E（停车）。
- **bit2（OFF3 急停）**：LV 直接由 `NOT EMG_stop` 控制；MV 经急停定时器 `TOf_1`（`ES_TIME`）延时后控制，提供安全联锁延时。

## 7. 给定控制

变频器的转速由频率给定 REF1（PZD2）决定。功能块支持本地和自动两种给定来源，并能无扰动切换。

### 7.1 自动 vs 本地选择

```
IF EXTINPUT THEN
    SET_A := SET_AUTO      （外部输入有效 → 用自动给定）
ELSE
    SET_A := SET_L         （否则用本地给定）
END_IF;
```

`EXTINPUT` 是模式切换开关：为真时走自动（DCS/上位机给定 `SET_AUTO`），为假时走本地（操作员手动给定 `SET_L`）。

### 7.2 本地升降速

当处于本地允许（`LOCAL_PERM`）且变频器正在运行（`RUNNING`）时，操作员可用升/降按钮微调频率：

```
IF LOCAL_PERM AND RUNNING THEN
    IF Freq_Up THEN SET_L := SET_L + 0.2;   （每周期 +0.2 Hz）
    IF Freq_Dn THEN SET_L := SET_L - 0.2;   （每周期 -0.2 Hz）
ELSE
    SET_L := SET_A;                          （非本地时跟踪自动给定）
END_IF;
```

### 7.3 无扰动切换的关键

无扰动切换靠"跟踪"实现：

- 本地模式下，`SET_L` 跟踪 `SET_A`（非本地允许时 `SET_L := SET_A`）；
- 自动模式下，`SET_AUTO` 跟踪 `SET_A`（`IF NOT EXTINPUT THEN SET_AUTO := SET_A`）。

这样无论从本地切自动，还是从自动切本地，两侧给定值始终相等，切换瞬间不会有频率突变，实现无扰动。

### 7.4 给定限幅

```
IF SET_L > Freq_Max THEN SET_L := Freq_Max;        （上限：最大频率）
IF (SET_L < Frq_min) OR NOT RUNNING THEN SET_L := Frq_min;  （下限：最小频率/停机归零）
```

- LV：下限为 `Frq_min`；
- MV：下限固定 5.0 Hz（中压变频器最低运行频率限制）。

零速开关（`ZSPSWITCH`）：当变频器停止且已允许运行时，强制给定归零，防止停机时仍有微小频率输出。

### 7.5 给定下发给变频器

```
OUTPUTDINT2.Value := REAL_TO_DINT(SET_L / Freq_Max × 20000.0 × K)
```

把工程单位 Hz 换算回 0~20000 的整数，写入 REF1。`OUTBOOL2_B0`（给定有效位）随 `SET_L>0` 置位，连同其他控制位经 `BOOL16_DINT_2` 写入 REF3（PZD4）。

## 8. 状态输出生成

功能块把变频器的原始状态字整理成几个面向 DCS 的友好布尔量：

| 输出 | 公式 | 含义 |
|------|------|------|
| `READY` | `INBOOL1_B0 AND INBOOL1_B1 AND READY1` | 就绪：准备合闸 + 准备操作 + 外部就绪 |
| `RUNNING` | `INBOOL1_B8 AND drive` | 运行中：达到给定 + 驱动命令有效 |
| `FAULT` | `= FAULT_G` | 故障：综合故障（超时或跳闸） |
| `STATUS` | `= INPUTDINT1.Value` | 原始状态字（供画面诊断） |
| `NO_Power` | `drive AND NOT B0`（锁存） | 断电：命令运行但准备合闸信号丢失 |
| `LOC_STOP` | `B9 AND NOT B1`（锁存） | 本地停止：运行中远程信号丢失 |

运行时间累计由 `TimerU_1`（`RUNNING` 保持时计时，`T_RST` 复位）完成。

## 9. 报警系统

功能块用 `AlarmCond` 报警条件块监测异常并推送报警。

### 9.1 LV 报警（4 个）

| 报警 | 信号源 | 触发条件 |
|------|--------|----------|
| 报警1 | `FAULT_G` | 启动后无响应/综合故障 |
| 报警2 | `INBOOL1_B3` | 变频器跳闸故障（SW bit3） |
| 报警3 | `INBOOL1_B7` | 变频器警告（SW bit7） |
| 报警4 | `LOC_STOP` | 本地停止（远程信号丢失） |

### 9.2 MV 报警（6 个）

MV 在 LV 的 4 个基础上增加 2 个：

| 报警 | 信号源 | 触发条件 |
|------|--------|----------|
| 报警5 | `TEMP_ALARM` | 电机温度过高（`motor_temp > temp_Limit` 且运行中，锁存） |
| 报警6 | `EMG_stop` | 急停激活 |

> LV/MV 差异：MV 多出的两个报警对应其特有的电机温度监控和急停定时器功能（见第 11 节）。

---

## 10. 事件记录

功能块用 7 个 `SimpleEventDetector` 记录关键操作与状态变化，供历史追溯：

| 事件 | 信号源 | 含义 |
|------|--------|------|
| 事件1 | `Single_start` | 单台启动 |
| 事件2 | `UNLOCK` | 工艺联锁释放 |
| 事件3 | `Local_permission` | 本地控制模式（MV 中由 `LOCAL_PERM AND NOT ZSPSWITCH` 计算） |
| 事件4 | `Single_stop` | 单台停止 |
| 事件5 | `start_lock_en` | 启动联锁断开 |
| 事件6 | `safe_lock_en` | 安全联锁断开 |
| 事件7 | `SP_Disable` | 速度给定禁用 |

事件记录与报警的区别：报警是异常状态推送，事件是操作/状态变化的留痕，两者都进 800XA 事件列表，便于事后追查"谁在什么时候做了什么"。

## 11. MV 特有功能

中压变频器功能块 `ABB_MV_VVVF` 相对低压多了以下几项，对应中压设备更高的安全与监控要求。

### 11.1 电机温度监控

```
motor_temp := DINT_TO_REAL(INPUTDINT6.Value) / 10.0    （PZD6/ACT5 换算为 °C）

RS_4.Set := (motor_temp > temp_Limit) AND RUNNING      （超温且运行中）
RS_4.R1  := Reset
TEMP_ALARM := RS_4.Q1                                   （温度报警，锁存）
```

中压电机通常配有温度传感器，经 RPBA-01 参数 916 映射到 ACT5（PZD6）。温度超过 `temp_Limit` 且变频器运行中时，触发 `TEMP_ALARM`（报警5），并锁存直到复位。

### 11.2 急停定时器

```
TOf_1.In := EMG_stop
TOf_1.PT := ES_TIME
OUTBOOL1_B2 := NOT TOf_1.Q     （OFF3 经延时）
```

LV 的急停是直接把 CW bit2 取反（立即快速停车）；MV 增加了一个断电延时定时器 `TOf_1`（`ES_TIME`），为安全联锁提供可配置的延时窗口，避免瞬态信号误触发急停，同时仍保证急停的最终执行。

### 11.3 频率/转速/百分比三种控制模式

MV 通过 `set_type` 选择给定单位，操作员可按习惯用频率（Hz）、转速（rpm）或百分比（%）输入给定，功能块自动换算：

```
CASE set_type OF
    0:  频率模式  →  percent_ref := SET_A / FEQ_MAX × 100
                    speed_ref   := SPEED_MAX × SET_A / FEQ_MAX
    1:  转速模式  →  SET_A       := speed_ref / SPEED_MAX × FEQ_MAX
                    percent_ref := speed_ref / SPEED_MAX × 100
    2:  百分比模式 →  SET_A       := FEQ_MAX × percent_ref / 100
                    speed_ref   := SPEED_MAX × percent_ref / 100
END_CASE;
```

切换模式时，当前给定值会换算到新单位，三种显示互相联动。对应的实际值也派生出来：`Frequency`（Hz）、`speed_act`（rpm）、`percent_act`（%），画面可同时显示。

> LV 只支持频率（Hz）单一模式，无 `set_type`、`SPEED_MAX`、`percent_ref/speed_ref` 等变量。

## 12. 故障跳闸电流捕获

变频器因故障跳闸时，记录跳闸瞬间的电机电流，便于事后分析故障原因（如过载跳闸时的电流峰值）。

```
F_Trig_2.Clk := RUNNING              （监视 RUNNING 的下降沿）
IF F_Trig_2_Q AND FAULT_G THEN       （RUNNING 刚由 1→0 且当前有故障）
    Current_lasttrip := Current;     （捕获当时电流）
END_IF;
```

原理：用下降沿触发器（`F_Trig_2`）检测"运行中"信号 `RUNNING` 由 1 变 0 的瞬间。如果这个瞬间恰好存在故障（`FAULT_G=1`），说明是故障导致的停机，于是把当前电流值 `Current` 存入 `Current_lasttrip`。这样运维人员事后查看 `Current_lasttrip` 就能知道跳闸时的负载电流，判断是过载、堵转还是其他原因。

## 13. 逻辑流程小结

把上述逻辑串成一条主线，一次完整的启停过程如下：

1. **待机**：联锁就位，变频器回送 RDY_ON=1，`drive=0`，CW=0x047E；
2. **启动**：组启动脉冲到来，启动条件全部满足 → RS 触发器置位 → `drive=1` → CW bit0=1（CW=0x047F）；
3. **使能运行**：`drive=1` 触发 500ms 延时，到时后 CW bit3=1，变频器进入允许运行（RDY_REF=1）；
4. **运行确认**：变频器达到给定，AT_SETPOINT=1 → `RUNNING=1`；运行监控定时器在超时前确认运行，否则报故障；
5. **调速**：操作员本地升/降或自动给定，`SET_L` 经限幅、换算写入 REF1；
6. **停止**：单台停止/急停/联锁断任一发生 → RS 触发器复位 → `drive=0` → CW bit0=0（CW=0x047E），变频器斜坡停车；急停则 CW bit2=0 快速停车；
7. **故障处理**：故障锁存 `FAULT_G=1`，触发报警，捕获跳闸电流；按复位按钮 `Reset` 清除故障（CW bit7 发复位脉冲）；
8. **全程**：报警与事件持续记录到 800XA 事件列表，运行时间累计。
