# WDH-31-550 PROFIBUS-DP 功能块开发包

## 1. 开发范围

本开发包依据以下资料编制：

- `WDH-31-550 Profibus-DP 通信手册V1.1`
- `wdhs2357.gsd`
- WDH-31-550 中英文用户说明书中的单向、双向典型回路
- `马保 -TEAE SOLO` 中现有 ABB 800xA 功能块的 Par / Var / Fun / Ext 结构和开发规则

已开发：

- `WDH550_SMOTOR_PROV`：单向直接起动电机
- `WDH550_SMOTORD_PROV`：双向电机、挡板开关执行机构
- `WDH550_BT2`：两套功能块共用的 Basic Type 2 I/O 数据类型

## 2. 采用的 PROFIBUS 报文

GSD 模块选择 `Basic Type 2`：

- 输入：20 bytes
- 输出：1 byte，Control Byte A
- 控制方式：边沿脉冲
- WDH 手册要求命令高电平至少保持 100 ms
- 功能块默认 `CmdPulseTime = T#200MS`

`WDH550_BT2` 与过程映像的连接如下：

| 字段 | 地址 | 内容 |
|---|---:|---|
| `wStatus_DI1` | IW0 | byte0 运行状态1；byte1 DI1～DI8 |
| `wDI2_Relay` | IW2 | byte2 DI9～DI16；byte3 Relay1～Relay8 |
| `wIa` | IW4 | A相电流，0.1 A |
| `wIb` | IW6 | B相电流，0.1 A |
| `wIc` | IW8 | C相电流，0.1 A |
| `wIunb` | IW10 | 电流不平衡度，0.1% |
| `wIr` | IW12 | 剩余电流，mA |
| `wUab` | IW14 | AB线电压，0.1 V |
| `wUbc` | IW16 | BC线电压，0.1 V |
| `wUca` | IW18 | CA线电压，0.1 V |
| `wControlA` | QB0 | 控制字节A |

## 3. Control Byte A

| bit | 功能 | 方式 |
|---:|---|---|
| 0 | 停车 | 0→1 边沿 |
| 1 | 起动A：正向、低速、开阀 | 0→1 边沿 |
| 2 | 故障复位 | 0→1 边沿 |
| 3 | 起动B：反向、高速、关阀 | 0→1 边沿 |
| 4 | 中控/DP模式 | 电平，1=DP控制 |
| 6 | 现场起动禁止 | 电平，1=禁止 |

WDH 参数【电机控制权限】必须设为以下方式之一：

- `远程`：控制字始终有效；
- `2位置AT`：由 Control Byte A bit4 决定控制权限，功能块参数 `DP_control_enable` 应保持 `TRUE`。

## 4. 导入顺序

1. 安装输出目录 `GSD\wdhs2357.gsd`。
2. 在硬件组态中插入 `Basic Type 2`。
3. 导入 `DataType\WDH550_BT2_DataType.xlsx`。
4. 新建相应 Function Block Type。
5. 依次导入该功能块目录内的：
   - `_Par.xlsx`
   - `_Var.xlsx`
   - `_Fun.xlsx`
   - `_Ext.xlsx`
6. 将 `_Code.st` 内容粘贴到功能块代码正文；不要再添加 `FUNCTION_BLOCK`、`VAR` 声明。
7. 将 `DP_IO` 的 11 个 `DwordIO` 字段连接到对应过程映像。
8. 在 Control Builder 中执行 Check / Compile。

## 5. 字节序联调

默认值：

- `First_byte_high = TRUE`
- `Control_byte_high = FALSE`

现场按以下顺序确认：

1. WDH 备妥时，确认 `READY = TRUE`。
2. 给 DI1 一个信号，确认 `DI_STATUS` 的 bit0 变化。
3. 对照面板电流确认 `IA / IB / IC`。
4. 若状态字节、DI字节互换，或电流值出现 256 倍关系，切换 `First_byte_high`。
5. 在空载、禁止起动条件下验证 Control Byte bit4 基线。
6. 若 WDH 未进入远程或命令无响应，再切换 `Control_byte_high` 并复核硬件连接。

`WDH31_550_协议映射与验证.xlsx` 的“联调测试”页包含可编辑原始字和公式解码结果。

## 6. 单向功能块说明

`WDH550_SMOTOR_PROV` 已实现：

- 单机起动、停车、复位；
- 组起、组停；
- 急停、工艺联锁、安全联锁、外部故障闭锁；
- WDH 备妥、运行、停车、远程、报警、跳闸状态；
- 起动无反馈超时；
- 单向块检测到正反向同时运行时产生 `STATUS_CONFLICT`；
- 三相电流、电流不平衡度、剩余电流、三相线电压；
- 事件和报警实例。

## 7. 双向功能块说明

`WDH550_SMOTORD_PROV` 中：

- L = Start A = 开、左、正向；
- R = Start B = 关、右、反向；
- 两个方向具有软件互锁；
- 同一扫描周期同时收到 L/R 起动请求时，两方向均不输出，并置位 `DIR_CONFLICT`；
- `FAULT1`：L方向起动无反馈；
- `FAULT2`：L方向行程超时；
- `FAULT3`：R方向起动无反馈；
- `FAULT4`：R方向行程超时；
- 默认起动反馈时间 `5 s`；
- 默认行程时间 `120 s`。

限位定义：

- `LIMITS_L = TRUE`：开/左限位已到；
- `LIMITS_R = TRUE`：关/右限位已到；
- `Open_limit_DI = 5`；
- `Close_limit_DI = 6`；
- `Limit_active_high = TRUE`；
- 不使用限位时将 `Use_limits = FALSE`。

DI5/DI6 是依据参考功能块的挡板回路默认值设置，必须与现场 WDH 的 DI 功能参数和最终施工图复核。功能块没有沿用旧代码中含义不清的常闭触点反相逻辑。

## 8. 协议资料差异

通讯手册存在两处定义差异，已按循环 Basic Type 2 处理：

- 循环数据 4.4 将 RS1 bit3 定义为“停车应答”；异步 record 101 将同一位置定义为“通信在线”。本功能块使用“停车应答”。
- Basic Type 2 表中电压单位简写为 V，附录和 record 102 给出 0.1 V；本功能块按 0.1 V 解析。电流不平衡度按 0.1% 解析。

Basic Type 2 固定报文只包含总报警、总故障位，不包含 4 字节详细报警和 4 字节详细跳闸信息。本版输出总 `ALARM / FAULT`；如项目需要保护类型明细，应在 GSD 中追加 Alarm info / Trip info 模块后另行扩展数据类型。
