# 变频器 PROFIBUS DP 数据映射对照表

> 项目：越南 F163 粉磨站 800XA 编程
> 适用功能块：`ABB_LV_VVVF`（低压，FPBA-01）、`ABB_MV_VVVF`（中压，RPBA-01）
> 通信方式：PROFIBUS DP，报文类型 PPO4（0 PKW + 6 PZD）
> 数据类型：`VVVFDT`（6 个输入 DINT + 6 个输出 DINT）
> 换算基准：20000 = 100% 频率；10 = 1 A 电流；10 = 1 kW 功率；10 = 1 °C 温度
> 编制日期：2026-07-16

---

## 1. 数据流向总览

数据从现场变频器最终呈现到 DCS 画面，共经历 5 个环节，每个环节的载体和单位都在变化：

```
┌──────────────┐    ┌───────────────┐    ┌────────────────┐    ┌──────────────┐    ┌──────────┐
│ 现场变频器    │───▶│ PROFIBUS DP   │───▶│ 800XA 控制器    │───▶│ 功能块变量    │───▶│ DCS 画面 │
│ (FPBA/RPBA)  │    │ (6 PZD 报文)  │    │ (VVVFDT 数据)  │    │ (工程单位)    │    │ (显示)   │
└──────────────┘    └───────────────┘    └────────────────┘    └──────────────┘    └──────────┘
   物理量              原始整数 DINT         DINT 成员             REAL 工程值          操作员可见
  频率/电流/...        0~20000 / 0~10000    INPUTDINTx.Value      Hz / A / kW / °C     数值/状态灯
```

各环节说明：

| 环节 | 载体 | 数据形式 | 说明 |
|------|------|----------|------|
| 1. 现场变频器 | FPBA-01(LV) / RPBA-01(MV) | 物理量 | 变频器内部参数（频率、电流、功率、温度等）经通信适配器采样 |
| 2. PROFIBUS DP | PZD1~PZD6（输入）/ PZD1~PZD6（输出） | 16 位整数字 | PPO4 报文：0 PKW + 6 PZD，周期性交换 |
| 3. 800XA 控制器 | `VVVFDT` 数据类型 | DINT | 输入 6 个 `INPUTDINT1~6`，输出 6 个 `OUTPUTDINT1~6`，每个含 `.Value` |
| 4. 功能块变量 | `ABB_LV_VVVF` / `ABB_MV_VVVF` 内部变量 | REAL / BOOL | 经换算公式转为工程单位，或经 `Dint_bool16` 拆分为位信号 |
| 5. DCS 画面 | 800XA Graphic | 工程值/状态 | 操作员监视的频率、电流、运行/故障指示灯等 |

> 通信行规差异：LV 功能块使用 **ABB Drives 行规**（FPBA-01 参数 51.27=0）；MV 功能块使用 **PROFIdrive 行规**（RPBA-01 默认）。两者在本项目中均采用 **20000 = 100%** 的换算基准，因此 REF/ACT 换算公式相同。

---

## 2. 输入映射表（变频器 → DCS）

变频器状态经 PROFIBUS DP 上传到 800XA，存入 `VVVFDT.INPUTDINT1~6`，功能块再换算为工程单位或拆分为位信号。

| PZD 字 | 含义 | VVVFDT 成员 | 拆分/换算 | 功能块变量 | 工程单位 | 换算公式 | LV | MV |
|--------|------|-------------|-----------|------------|----------|----------|----|----|
| PZD1 | 状态字 SW | `INPUTDINT1.Value` | `Dint_bool16_1` 拆分 | `INBOOL1_B0~B15` | 位(BOOL) | 逐位提取 | 是 | 是 |
| PZD2 | ACT1 实际频率 | `INPUTDINT2.Value` | 频率换算 | `Frequency` | Hz | `Frequency = raw / 20000 × FreqMax × K` | 是 | 是 |
| PZD3 | ACT2 电机电流 | `INPUTDINT3.Value` | 电流换算；MV 另经 `Dint_bool16_3` 拆位 | `Current` | A | `Current = raw / 10` | 是 | 是 |
| PZD4 | ACT3 实际值3 | `INPUTDINT4.Value` | 预留（MV 典型映射转矩，10=1%） | —（预留） | — | 未换算（按需扩展） | 预留 | 预留 |
| PZD5 | ACT4 电机功率 | `INPUTDINT5.Value` | 功率换算 | `power` | kW | `power = raw / 10` | 是 | 是 |
| PZD6 | ACT5 电机温度 | `INPUTDINT6.Value` | 温度换算 | `motor_temp` | °C | `motor_temp = raw / 10` | 否 | **仅 MV** |

换算公式中变量说明：

- LV 功能块最大频率变量名为 `Freq_Max`，标定系数为 `K`；
- MV 功能块最大频率变量名为 `FEQ_MAX`，标定系数为 `KK`；
- 频率换算：`Frequency = DINT_TO_RAW(INPUTDINT2.Value) / 20000.0 × 最大频率 × 标定系数`；
- 若改用 PROFIdrive 的 4000h 模式（16384=100%），需将公式中的 20000 改为 16384。

> LV/MV 差异：LV 不读取电机温度（PZD6 未使用）；MV 通过 RPBA-01 参数 916 将 ACT5 映射为电机温度，并参与温度报警逻辑（见 `motor_temp`、`TEMP_ALARM`）。MV 还额外派生 `percent_act`（百分比）和 `speed_act`（转速 rpm）两个工程值。

---

## 3. 输出映射表（DCS → 变频器）

DCS 控制命令经功能块组装后写入 `VVVFDT.OUTPUTDINT1~6`，再经 PROFIBUS DP 下发到变频器。

| PZD 字 | 含义 | VVVFDT 成员 | 组装方式 | 功能块变量 | 工程单位 | 换算公式 | LV | MV |
|--------|------|-------------|----------|------------|----------|----------|----|----|
| PZD1 | 控制字 CW | `OUTPUTDINT1.Value` | `BOOL16_DINT_1` 由 `OUTBOOL1_B0~B15` 合成 | `OUTBOOL1_Bx` | 位(BOOL) | 逐位合成 | 是 | 是 |
| PZD2 | REF1 频率给定 | `OUTPUTDINT2.Value` | 频率给定换算 | `SET_L` | Hz | `raw = SET_L / FreqMax × 20000 × K` | 是 | 是 |
| PZD3 | REF2 给定2 | `OUTPUTDINT3.Value` | 预留 | — | — | 未使用 | 预留 | 预留 |
| PZD4 | REF3 控制位 | `OUTPUTDINT4.Value` | `BOOL16_DINT_2` 由 `OUTBOOL2_B0~B15` 合成 | `OUTBOOL2_Bx` | 位(BOOL) | 逐位合成 | 是 | 是 |
| PZD5 | REF4 给定4 | `OUTPUTDINT5.Value` | 预留 | — | — | 未使用 | 预留 | 预留 |
| PZD6 | REF5 给定5 | `OUTPUTDINT6.Value` | 预留 | — | — | 未使用 | 预留 | 预留 |

换算公式中变量说明：

- REF1 频率给定换算（LV）：`OUTPUTDINT2.Value = REAL_TO_DINT(SET_L / Freq_Max × 20000.0 × K)`；
- REF1 频率给定换算（MV）：`OUTPUTDINT2.Value = REAL_TO_DINT(SET_L / FEQ_MAX × 20000.0 × KK)`；
- `OUTBOOL2_B0`（给定有效位）：当 `SET_L > 0.0` 时置 TRUE，否则 FALSE；
- 其余 `OUTBOOL2_B1~B15` 为驱动特定/预留位。

> LV/MV 差异：两者输出 PZD 映射结构一致，差异仅在最大频率变量名（`Freq_Max` vs `FEQ_MAX`）与标定系数（`K` vs `KK`）。MV 的 `SET_L` 还可由频率/转速/百分比三种模式换算得到（见功能块逻辑说明）。

## 4. 控制字（CW）位映射表

控制字由 `OUTBOOL1_B0~B15` 逐位组装后写入 `OUTPUTDINT1`（PZD1），用于控制变频器启停与运行。

| 位号 | 名称 | 功能块变量 | 设定逻辑 | 说明 | LV | MV |
|------|------|------------|----------|------|----|----|
| B0 | OFF1 | `OUTBOOL1_B0` | `= drive` | 1=运行（斜坡启动）；0=斜坡停车 | 是 | 是 |
| B1 | OFF2 | `OUTBOOL1_B1` | `= TRUE` | 1=运行；0=自由停车（惯性停） | 是 | 是 |
| B2 | OFF3 | `OUTBOOL1_B2` | LV: `= NOT EMG_stop`；MV: `= NOT TOf_1.Q` | 1=运行；0=急停快速停车。MV 经 `TOf_1`（`ES_TIME`）延时 | 是 | 是（带延时） |
| B3 | OPERATION_ENABLE | `OUTBOOL1_B3` | `= TOn_1.Q` | 1=允许运行；驱动命令后经 500ms 延时置位 | 是 | 是 |
| B4 | RAMP_OUT_ZERO | `OUTBOOL1_B4` | `= TRUE` | 1=正常；0=强制斜坡输出为零 | 是 | 是 |
| B5 | RAMP_HOLD | `OUTBOOL1_B5` | `= TRUE` | 1=允许斜坡；0=暂停斜坡 | 是 | 是 |
| B6 | RAMP_IN_ZERO | `OUTBOOL1_B6` | `= TRUE` | 1=正常；0=强制斜坡输入为零 | 是 | 是 |
| B7 | RESET | `OUTBOOL1_B7` | `= Reset` | 0→1 上升沿复位变频器故障 | 是 | 是 |
| B8 | 保留/INCHING_1 | `OUTBOOL1_B8` | `= FALSE` | LV 保留；MV 点动1（未使用） | 保留 | 点动1 |
| B9 | 保留/INCHING_2 | `OUTBOOL1_B9` | `= FALSE` | LV 保留；MV 点动2（未使用） | 保留 | 点动2 |
| B10 | REMOTE_CMD | `OUTBOOL1_B10` | `= TRUE` | 1=总线控制使能（远程） | 是 | 是 |
| B11 | EXT_CTRL_LOC | `OUTBOOL1_B11` | `= FALSE` | 0=EXT1；1=EXT2（外部控制地选择） | 是 | 是 |
| B12~B15 | 驱动特定 | `OUTBOOL1_B12~B15` | `= FALSE` | 驱动特定/保留 | 保留 | 保留 |

控制字典型十六进制值：

| 工况 | 十六进制 | 二进制（bit15~bit0） | 含义 |
|------|----------|----------------------|------|
| 停车/就绪 | `0x047E` | `0000 0100 0111 1110` | bit0=0（OFF1 停），bit1~6=1，bit10=1 |
| 运行 | `0x047F` | `0000 0100 0111 1111` | bit0=1（OFF1 运行），其余同上 |
| 故障复位 | `0x04FE` | `0000 0100 1111 1110` | bit7=1（复位），随后回到 `0x047E` |
| 急停 | `0x043E` | `0000 0100 0011 1110` | bit2=0（OFF3 急停） |

> LV/MV 差异：B3 位在 LV（ABB Drives 行规）手册中命名为 `INHIBIT_OPERATION`（反逻辑：1=允许运行），在 MV（PROFIdrive 行规）中命名为 `OPERATION_ENABLE`（1=允许运行），两者功能一致，本表统一采用 `OPERATION_ENABLE`。B2（OFF3）在 LV 中直接由 `EMG_stop` 取反，在 MV 中经急停定时器 `TOf_1`（`ES_TIME`）延时后再取反，提供安全联锁延时。

## 5. 状态字（SW）位映射表

状态字由 `INPUTDINT1`（PZD1）经 `Dint_bool16_1` 拆分为 `INBOOL1_B0~B15`，用于监视变频器状态。

| 位号 | 名称 | 功能块变量 | 说明 | 用途 | LV | MV |
|------|------|------------|------|------|----|----|
| B0 | RDY_ON | `INBOOL1_B0` | 1=准备合闸（Ready to switch on） | 启动条件、LOCKED 判断、断电检测 | 是 | 是 |
| B1 | RDY_RUN | `INBOOL1_B1` | 1=准备操作（Ready to operate） | LV 启动条件、READY 状态、本地停止检测 | 是 | 是 |
| B2 | RDY_REF | `INBOOL1_B2` | 1=允许运行（Operation enabled） | 运行监控 `TOn_3`、零速开关判断 | 是 | 是 |
| B3 | TRIPPED | `INBOOL1_B3` | 1=故障跳闸 | `FAULT_G` 锁存、报警2 | 是 | 是 |
| B4 | OFF_2_STA | `INBOOL1_B4` | 1=OFF2 无效（未自由停） | 状态监视 | 是 | 是 |
| B5 | OFF_3_STA | `INBOOL1_B5` | 1=OFF3 无效（未急停） | 状态监视 | 是 | 是 |
| B6 | SWC_ON_INHIB | `INBOOL1_B6` | 1=禁止合闸（Switch-on inhibit） | MV 启动条件（`NOT B6`） | 是 | 是（启动联锁） |
| B7 | ALARM | `INBOOL1_B7` | 1=警告/报警 | 报警3 | 是 | 是 |
| B8 | AT_SETPOINT | `INBOOL1_B8` | 1=运行中（达到给定） | `RUNNING` 状态、运行时间计数 | 是 | 是 |
| B9 | REMOTE | `INBOOL1_B9` | 1=远程控制 | 本地停止检测 `LOC_STOP` | 是 | 是 |
| B10 | ABOVE_LIMIT | `INBOOL1_B10` | 1=超限（高于监控限值） | 状态监视 | 是 | 是 |
| B11 | EXT_CTRL_LOC | `INBOOL1_B11` | 1=已选择 EXT2 | 状态监视 | 是 | 是 |
| B12 | EXT_RUN_ENABLE | `INBOOL1_B12` | 1=收到运行使能 | 进入 OPERATION ENABLED 的前提（LV） | 是 | 是 |
| B13~B14 | 驱动特定 | `INBOOL1_B13~B14` | 驱动特定 | 预留 | 保留 | 保留 |
| B15 | FBA_ERROR | `INBOOL1_B15` | 1=现场总线适配器错误 | 总线故障监视 | 是 | 是 |

> LV/MV 差异：B6（禁止合闸）在 MV 启动条件中被显式检查（`NOT INBOOL1_B6`），LV 启动条件未直接检查 B6。B12（EXT_RUN_ENABLE）在 LV 中是进入 OPERATION ENABLED 状态的前提条件。其余位定义两者一致。

## 6. LV 与 MV 映射差异汇总

| 对比项 | ABB_LV_VVVF（低压） | ABB_MV_VVVF（中压） |
|--------|---------------------|---------------------|
| 通信适配器 | FPBA-01 | RPBA-01 |
| GSD 文件 | ABB10959.gsd（Ident 0x0959） | ABB10812.GSD（Ident 0x0812） |
| 通信行规 | ABB Drives（51.27=0） | PROFIdrive（默认） |
| 适用变频器 | ACS355/ACSM1/ACS850/ACQ810/ACS880 | ACS600/ACS800/ACS1000/ACS5000/DCS800 |
| 最大频率变量 | `Freq_Max` | `FEQ_MAX` |
| 标定系数 | `K` | `KK` |
| PZD6（ACT5 温度） | 不使用 | 使用，`motor_temp = raw/10`，含 `TEMP_ALARM` |
| PZD4（ACT3） | 驱动特定，预留 | 典型映射转矩（10=1%），预留 |
| CW 位3 命名 | INHIBIT_OPERATION（反逻辑） | OPERATION_ENABLE |
| CW 位2（OFF3） | `NOT EMG_stop`（直接） | `NOT TOf_1.Q`（经 `ES_TIME` 延时） |
| 启动条件 | 含 `RDY_RUN`（B1） | 含 `READY1`、`NOT SWC_ON_INHIB`（B6） |
| 控制模式 | 频率（Hz）单模式 | 频率/转速/百分比三模式（`set_type`） |
| 报警数量 | 4 个 | 6 个（增加温度高、急停） |
| 派生工程值 | 频率、电流、功率 | 频率、电流、功率、温度、百分比、转速 |

## 7. 备注

1. 所有 PZD 字均为 16 位整数字，在 800XA 中以 DINT（32 位）存储，高 16 位补零/符号扩展，换算时取低 16 位有效值。
2. `VVVFDT` 数据类型的每个 DINT 成员结构为 `.Value`（数值）加通信质量戳，功能块通过 `.Value` 读写数值。
3. ACT 实际值的具体物理含义由通信适配器参数（FPBA-01/RPBA-01 参数 916）配置映射，本表按项目默认映射列出；如调整参数 916，需同步更新本表与功能块换算逻辑。
4. 若通信行规切换为 PROFIdrive 4000h 模式（16384=100%），需将所有 REF/ACT 换算公式中的 20000 改为 16384。
