## 二、控制过程

### 2.1 启动/停止控制

**启动过程：**
1. DCS 操作员按下"启动"按钮 → `DCS_Start = TRUE`
2. TP_Start 定时器产生 1 秒脉冲 → `TP_Start.Q = TRUE`（持续1秒）
3. 控制字1 Bit 0 置 1 → 发送给皮带秤控制器
4. 皮带秤启动后，状态字1 Bit 0 变为 1 → `Running = TRUE`
5. SimpleEventDetector_1 检测到 `Running` 的上升沿 → 记录"启动"事件

**停止过程：**
1. DCS 操作员按下"停止"按钮 → `DCS_Stop = TRUE`
2. TP_Stop 定时器产生 1 秒脉冲 → `TP_Stop.Q = TRUE`
3. 控制字1 Bit 1 置 1 → 发送给皮带秤控制器
4. 皮带秤停止后，状态字1 Bit 0 变为 0 → `Running = FALSE`
5. SimpleEventDetector_2 检测到 `Running` 的下降沿 → 记录"停止"事件

**关键：停止事件需要手动边沿检测**
- SimpleEventDetector 内部只检测上升沿
- 停止是下降沿，需要用 `(NOT Running) AND prev_running` 手动构造上升沿
- `prev_running` 在每个周期末尾更新为当前 `Running` 值

### 2.2 故障复位控制

1. DCS 操作员按下"复位"按钮 → `DCS_Reset = TRUE`
2. TP_Reset 定时器产生 1 秒脉冲 → `TP_Reset.Q = TRUE`
3. 控制字1 Bit 2 置 1 → 发送给皮带秤控制器
4. 皮带秤清除故障状态

### 2.3 流量设定值控制（配料秤）

1. DCS 操作员在画面上输入流量设定值 → `Flow_Setpoint = xxx kg/h`
2. 功能块将 `Flow_Setpoint` 直接写入 `dpOut_FlowSet.Value`
3. 皮带秤控制器接收设定值，调节给料速度

**皮带计量秤不接此参数**，功能块代码仍然执行写入操作，但设备会忽略该值。

### 2.4 批量控制

**批量方式选择：**
1. `Select_Batch = TRUE` → 控制字1 Bit 16 置 1
2. 设备进入批量模式 → `Batch_Selected = TRUE`
3. 当批量实际激活时 → `Batch_Active = TRUE`
4. SimpleEventDetector_3 记录"批量激活"事件

**批量退出/中断：**
- `Exit_Batch = TRUE` → Bit 17 → 正常退出批量
- `Interrupt_Batch = TRUE` → Bit 18 → 紧急中断批量

### 2.5 累积量清零

- `Accum1_Reset = TRUE` → 控制字1 Bit 6 → 累积量1 清零
- `Accum2_Reset = TRUE` → 控制字1 Bit 7 → 累积量2 清零

### 2.6 预给料机控制

- `Activate_PreFeeder = TRUE` → 控制字1 Bit 30 → 激活预给料机
- `Stop_PreFeeder = TRUE` → 控制字1 Bit 31 → 停止预给料机
  - Bit 31 需要特殊处理：`out_ctrl1_int - 2147483647 - 1` 避免 DInt 溢出

### 2.7 标定控制

| 命令 | 参数名 | 控制字2 Bit | 说明 |
|---|---|---|---|
| 去皮重 | Cmd_Tare | Bit 16 | TW去皮重 |
| 调零 | Cmd_Zero | Bit 17 | >0<调零 |
| 量程标定 | Cmd_SpanCal | Bit 18 | CW量程标定 |
| 脉冲标定 | Cmd_PulseCal | Bit 19 | LB脉冲标定 |
| 应用 | Cmd_Apply | Bit 27 | 确认执行 |
| 取消 | Cmd_Cancel | Bit 28 | 取消操作 |
| 获取时间 | Cmd_GetTime | Bit 29 | 读取设备时间 |

标定过程中 → `Cal_Running = TRUE` → SimpleEventDetector_4 记录"标定运行"事件

## 三、连锁保护

### 3.1 释放信号连锁

**控制字1 Bit 3（释放位）始终置 1**，这是代码中硬编码的：

```st
out_ctrl1_int := out_ctrl1_int + 8 ;   (* Bit 3: 始终置1 *)
```

这意味着每个周期发送的控制字1都会包含释放信号。如果设备没有收到释放信号，会拒绝执行任何命令。

### 3.2 无释放信号报警

当设备返回 `No_Release = TRUE`（状态字1 Bit 1）时：
- AlarmCond_3 生成报警，严重程度 500（警告级别）
- 提示操作员设备可能无法接收命令

### 3.3 命令脉冲保护

所有 Start/Stop/Reset 命令都经过 TP 定时器处理，生成固定 1 秒的脉冲：
- 防止按钮长按导致重复发送
- 确保命令宽度一致，设备可靠接收
- 其他命令（标定、批量等）直接打包，因为它们通常是短时操作

### 3.4 信号滤波保护

三个关键状态信号经过 TOf（断电延时）滤波：

| 信号 | TOf 实例 | 滤波时间 | 作用 |
|---|---|---|---|
| Running | TOf_Run | 1 秒 | 防止运行信号瞬间抖动 |
| Heavy_Alarm | TOf_Alarm | 1 秒 | 防止报警信号误触发 |
| Warning | TOf_Warn | 1 秒 | 防止警告信号误触发 |

**滤波原理：** 信号变为 FALSE 后，延迟 1 秒才真正变为 FALSE。如果信号在 1 秒内恢复，则不会产生中断。这样滤除通讯中短于 1 秒的噪声脉冲。

## 四、报警信息

### 4.1 报警列表

| 序号 | 报警名称 | 触发信号 | 严重程度 | 报警消息 | 说明 |
|---|---|---|---|---|---|
| 1 | 重报警 | Heavy_Alarm | 800 | Belt Scale Heavy Alarm | 设备综合重报警，需立即处理 |
| 2 | 警告 | Warning | 500 | Belt Scale Warning | 设备综合警告，需关注 |
| 3 | 无释放信号 | No_Release | 500 | Belt Scale No Release | 设备未收到释放信号，可能无法控制 |

**严重程度说明：**
- **800**：高优先级，在操作员画面上红色显示，通常需要确认后才能消失
- **500**：中优先级，在操作员画面上黄色显示

### 4.2 极限值报警（状态输出，非 AlarmCond）

以下信号不生成系统报警，但会在画面上显示为指示灯：

| 信号 | 说明 | 显示方式 |
|---|---|---|
| Flow_Upper_Limit | 实际流量超过上限 | 红色指示灯 |
| Flow_Lower_Limit | 实际流量低于下限 | 红色指示灯 |
| Load_Upper_Limit | 皮带负荷超过上限 | 红色指示灯 |
| Load_Lower_Limit | 皮带负荷低于下限 | 红色指示灯 |
| Speed_Upper_Limit | 皮带速度超过上限 | 红色指示灯 |
| Speed_Lower_Limit | 皮带速度低于下限 | 红色指示灯 |

### 4.3 事件记录

| 序号 | 事件名称 | 触发条件 | 消息内容 |
|---|---|---|---|
| 1 | 启动事件 | Running 上升沿 | Belt Scale Start |
| 2 | 停止事件 | Running 下降沿 | Belt Scale Stop |
| 3 | 批量激活事件 | Batch_Active 上升沿 | Batch Mode Active |
| 4 | 标定运行事件 | Cal_Running 上升沿 | Calibration Running |
| 5 | 重报警事件 | Heavy_Alarm 上升沿 | Belt Scale Heavy Alarm |

**事件与报警的区别：**
- **报警（AlarmCond）**：持续监控信号状态，信号为 TRUE 时报警保持，信号变 FALSE 时报警消失
- **事件（SimpleEventDetector）**：只在信号变化的那一刻记录一条日志，不持续

## 五、数据流总结

### 5.1 输入数据流

```
皮带秤硬件 → PROFIBUS DP → 800XA I/O 通道 (DintIO/RealIO)
→ ST代码 .Value 读取 → DInt/Real 中间变量
→ MOD/DIV 解包 → Bool 状态信号 → TOf 滤波 → 输出到 DCS 画面
```

### 5.2 输出数据流

```
DCS 操作员命令 → Bool/Real 参数
→ TP 脉冲处理 (Start/Stop/Reset) 
→ IF 累加打包到 DInt → .Value 写入 DintIO
→ 800XA I/O 通道 → PROFIBUS DP → 皮带秤硬件
```

### 5.3 关键中间变量

| 变量名 | 类型 | 用途 |
|---|---|---|
| in_status1_int | DInt | 状态字1解包中间变量 |
| in_status2_int | DInt | 状态字2解包中间变量 |
| out_ctrl1_int | DInt | 控制字1打包中间变量 |
| out_ctrl2_int | DInt | 控制字2打包中间变量 |
| prev_running | Bool | 上一周期运行状态（停止事件检测用） |
