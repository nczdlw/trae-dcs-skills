# ABB 变频器功能块开发说明

> 越南F163粉磨站 800XA 编程项目
> 功能块：ABB_LV_VVVF（低压）/ ABB_MV_VVVF（中压）
> 平台：ABB 800XA V6.1.0，ST 语言，中英文注释
> 日期：2026-07-16

---

## 一、项目背景

越南F163粉磨站在生产过程中使用了大量ABB变频器来驱动各类电机（如磨机、风机、泵类负载）。这些变频器分为两类：

- **低压变频器**：ACS355、ACSM1、ACS850、ACQ810、ACS880 等，通过 **FPBA-01** 通信适配器接入 PROFIBUS DP 总线。
- **中压变频器**：ACS600、ACS800、ACS1000、ACS5000、DCS800 等，通过 **RPBA-01** 通信适配器接入 PROFIBUS DP 总线。

整个粉磨站的控制系统采用 ABB 800XA DCS（V6.1.0 版本）。所有变频器都需要通过 PROFIBUS DP 现场总线接入 800XA，由 DCS 统一进行启停控制、频率给定、状态监视和故障报警管理。在此之前，项目中已有基于 FBD（功能块图）方式编写的老功能块（ACS550、ACS800），但缺少一套统一、标准化、可复用的ST语言功能块来覆盖低压和中压两种场景。

本次开发的目标就是补齐这一块：用ST（结构化文本）语言编写两套标准化功能块，分别对应低压和中压变频器，使后续同类设备可以直接套用，减少重复开发工作。

---

## 二、开发目标

创建两个标准化的变频器控制功能块，实现以下四项核心功能：

| 功能 | 说明 |
|------|------|
| **启停控制** | 支持组启动、单台启动、单台停止、急停、故障复位，配合联锁条件实现安全启停 |
| **频率给定** | 支持自动给定和本地给定两种模式，本地模式下可手动加减速，切换时无扰动 |
| **状态监控** | 实时读取变频器状态字，解析出就绪、运行、故障、本地停止、断电等状态，并换算频率、电流、功率等实际值 |
| **报警管理** | 自动生成驱动故障、警告、启动无响应、本地停止等报警，中压版额外增加温度过高和急停激活报警 |

两套功能块在设计上保持统一的接口风格和代码结构，差异部分主要体现在中压版增加了温度监控、急停定时器和多控制模式（频率/转速/百分比）。

## 三、开发过程

整个开发过程分为六个步骤，下面按时间顺序逐一说明。

### 第一步：理清GSD文件

GSD文件是PROFIBUS DP从站设备的"身份证"，里面定义了设备的模块配置、通信参数和报文格式。在动手写代码之前，首先要搞清楚低压和中压变频器分别用哪个GSD文件、对应哪个通信适配器。

经过梳理，确认如下对应关系：

| 通信适配器 | GSD文件 | 设备标识号(Ident) | 适用变频器 |
|-----------|---------|------------------|-----------|
| FPBA-01（低压） | ABB10959.gsd | 0x0959 | ACS355、ACSM1、ACS850、ACQ810、ACS880 |
| RPBA-01（中压） | ABB10812.GSD | 0x0812 | ACS600、ACS800、ACS1000、ACS5000、DCS800 |

项目资料目录下提供了完整的GSD文件库，包含FPBA-01的多个版本（v.2145及更早 / v.2161及以后）和DPV0/DPV1两种模式。本次开发采用的是DPV1模式的GSD文件，因为DPV1支持更灵活的参数访问。

### 第二步：研究手册确定通信行规、CW/SW位定义、换算系数

这一步是整个开发中最关键的环节。需要研读两本手册：

- **FPBA-01 用户手册**（EN_FPBA01_UM_E.pdf）：低压变频器通信适配器手册
- **RPBA-01 用户手册**（RPBA01_MANUAL.pdf）：中压变频器通信适配器手册
- **S7集成指南**（EN_Simatic_S7_Profibus_DP_B.pdf）：虽然是西门子S7的文档，但其中对PROFIBUS DP通信行规和报文结构的说明对800XA同样适用

通过研读手册，确定了以下关键技术参数：

**1）通信行规（Profile）**

FPBA-01和RPBA-01都支持两种通信行规，两者的控制字/状态字位定义和换算系数有所不同：

| 对比项 | ABB Drives 行规 | PROFIdrive 行规 |
|--------|----------------|----------------|
| 频率给定换算 | 20000 = 100% | 16384(0x4000) = 100% |
| 实际值换算 | 20000 = 100% | 16384(0x4000) = 100% |
| CW位3名称 | INHIBIT_OPERATION | OPERATION_ENABLE |
| FPBA-01参数51.27 | 0 = ABB Drives | 1 = PROFIdrive |

本次开发中：
- **低压功能块（ABB_LV_VVVF）使用 ABB Drives 行规**（FPBA-01默认），换算系数 20000 = 100%。
- **中压功能块（ABB_MV_VVVF）使用 PROFIdrive 行规**（RPBA-01默认），同样使用 20000 = 100% 换算。

如果将来需要切换行规，只需在代码中将换算系数 20000 改为 16384 即可，代码注释中已明确标注。

**2）控制字（CW）位定义**

控制字是DCS发给变频器的16位命令字，每一位代表一个控制命令：

| 位 | 名称 | 说明 |
|----|------|------|
| 0 | OFF1 | 1=运行，0=斜坡停车 |
| 1 | OFF2 | 1=运行，0=自由停车（惯性停车） |
| 2 | OFF3 | 1=运行，0=快速急停 |
| 3 | OPERATION_ENABLE | 1=允许运行（使能操作） |
| 4 | RAMP_OUT_ZERO | 1=正常，0=强制斜坡输出为零 |
| 5 | RAMP_HOLD | 1=允许斜坡，0=暂停斜坡 |
| 6 | RAMP_IN_ZERO | 1=正常，0=强制斜坡输入为零 |
| 7 | RESET | 0→1上升沿触发故障复位 |
| 10 | REMOTE_CMD | 1=总线控制使能 |

常用的控制字十六进制值：
- STOP/就绪：`0x047E`
- RUN/运行：`0x047F`
- 故障复位：`0x04FE`（bit7置1后需回到`0x047E`）
- 急停：`0x043E`（bit2置0）

**3）状态字（SW）位定义**

状态字是变频器返回给DCS的16位状态字，每一位代表一个状态：

| 位 | 名称 | 说明 |
|----|------|------|
| 0 | RDY_ON | 1=准备合闸（就绪） |
| 1 | RDY_RUN | 1=准备操作 |
| 2 | RDY_REF | 1=允许运行（操作已使能） |
| 3 | TRIPPED | 1=故障（跳闸） |
| 7 | ALARM | 1=警告 |
| 8 | AT_SETPOINT | 1=运行中（已达到给定） |
| 9 | REMOTE | 1=远程控制 |
| 12 | EXT_RUN_ENABLE | 1=收到运行使能（仅ABB Drives行规） |
| 15 | FBA_ERROR | 1=总线适配器错误 |

**4）换算系数**

变频器通过PROFIBUS DP传上来的是整数（DINT）原始值，需要换算成工程单位：

| 信号 | 原始范围 | 换算公式 | 工程单位 |
|------|---------|---------|---------|
| 频率（REF/ACT） | 0~20000 | 原始值 / 20000 × 最大频率 | Hz |
| 电流（ACT） | 0~10000 | 原始值 / 10 | A |
| 功率（ACT） | 0~10000 | 原始值 / 10 | kW |
| 温度（ACT，中压专用） | 0~10000 | 原始值 / 10 | °C |

### 第三步：参考老功能块的代码和Excel格式

项目中已有两套老功能块可以作为参考：

- **ACS550**：低压变频器老功能块，采用FBD（功能块图）方式编写
- **ACS800**：中压变频器老功能块，同样采用FBD方式编写

每个老功能块都包含以下文件：
- `*_CODE.pdf` / `*_CODE2.pdf`：代码段（因原工程是FBD，这里导出为PDF查看）
- `*_VAR.xlsx`：变量声明表
- `*_PAR.xlsx`：参数声明表
- `*_FUN.xlsx`：功能块实例声明表
- `VVVFDT.xlsx`：VVVF数据类型定义

参考老功能块主要解决了两个问题：

1. **确认变量命名和接口风格**：老功能块已经定义了一套成熟的输入输出信号（如Group_start、Single_start、READY、RUNNING等），新功能块沿用了这套命名，保证操作员画面和联锁逻辑的一致性。

2. **确认Excel文件格式**：800XA的功能块必须配套VAR/PAR/FUN三张Excel表才能导入工程。老功能块的Excel格式就是标准模板，包括合并标题行、列头、数据行、日期页码行等，新功能块严格照此格式制作。

但老功能块有一个关键局限：它们用FBD图形方式编写，无法直接以ST文本形式使用。新功能块需要把FBD逻辑"翻译"成ST语言，同时还引入了TAYNINH库的自定义FB来替代标准库的DINTTOBOOL16/BOOL16TODINT。

### 第四步：编写ST代码

800XA的功能块代码分为两个段：

- **Code段**：放置FB实例调用（如Dint_bool16、BOOL16_DINT、RS、TOn、TP等），相当于FBD中的功能块连线。
- **Code2段**：放置纯ST逻辑（如IF/CASE语句、赋值运算），处理给定值控制、实际值换算、报警生成等。

| Code | 4 | 驱动启停逻辑（RS_1） |
| Code | 5 | 联锁与安全逻辑 |
| Code | 6 | 运行时间监控（TOn_3, SR_1） |
| Code | 7 | 运行使能定时器（TOn_1，500ms延时） |
| Code | 8 | 状态输出生成（READY/RUNNING/FAULT/STATUS） |
| Code | 9 | 断电/本地停止检测（RS_2, RS_3） |
| Code | 10 | 故障跳闸检测（F_Trig_2，捕获跳闸电流） |
| Code | 11 | 控制字生成（BOOL16_DINT_1） |
| Code | 12 | 给定值生成（BOOL16_DINT_2） |
| Code2 | A | 速度频率给定控制（Freq_Up/Freq_Dn） |

**中压功能块（ABB_MV_VVVF_Code.st）的代码结构：**

- Section 4：新增急停定时器（TOf_1，ES_TIME）

### 第五步：创建Excel文件

每个功能块需要配套4类Excel文件才能在800XA中完整使用：

| 文件类型 | 文件名（低压/中压） | 作用 |
|---------|---------------------|------|
| **VAR** | ABB_LV_VVVF_VAR.xlsx / ABB_MV_VVVF_VAR.xlsx | 声明功能块内部变量（局部变量、中间变量） |
| **PAR** | ABB_LV_VVVF_PAR.xlsx / ABB_MV_VVVF_PAR.xlsx | 声明功能块参数（输入、输出、输入输出引脚） |
| **FUN** | ABB_LV_VVVF_FUN.xlsx / ABB_MV_VVVF_FUN.xlsx | 声明ST代码中调用的所有FB实例 |
| **DataType** | VVVFDT_DataType.xlsx | 定义VVVFDT数据类型（6输入DINT + 6输出DINT，对应PPO4报文） |

此外还有两个TAYNINH库自定义FB的参数表：
- `Dint_bool16_par.xlsx`：Dint_bool16功能块的参数定义
- `BOOL16_DINT_PAR.xlsx`：BOOL16_DINT功能块的参数定义

Excel文件格式严格遵循老功能块（ACS550/ACS800）的模板：
- 第1行：合并标题行（Function Block Type - TAYNINH.xxx - Variables/Parameters/Function Blocks）
- 第2行：列头
- 数据行：序号 + 内容
- 最后行：日期 + 页码

PAR表中的Direction（方向）字段取值：
- `in`：只读输入参数（如Group_start、Reset）
- `out`：只写输出参数（如READY、RUNNING、Frequency）
- `in_out`：读写参数（如SET_AUTO、SET_L，既需要读取又需要在代码中修改）

### 第六步：编译调试，修复18个编译错误

代码和Excel文件写完后，导入800XA工程工具进行编译。第一次编译时出现了18个错误，主要集中在以下几个方面。下面按错误类型逐一说明修复过程。

**错误类型1：变量名重复声明（Error 1000）**

800XA编译器对变量名大小写不敏感，`Local_permission`和`LOCAL_PERMISSION`被视为同一个变量。更严重的是，`SET_AUTO`这个变量同时在VAR表和PAR表中声明了，导致冲突。

修复方法：
- 将`SET_AUTO`从VAR表中删除，只在PAR表中声明，方向设为`in_out`。
- 检查所有变量名，确保VAR表和PAR表合并后全局唯一。

**错误类型2：in_out方向带了retain属性（Error 1005）**

`SET_AUTO`参数需要保持断电前的值，所以最初加了`retain`属性，但它的方向是`in_out`（by_ref引用传递），800XA不允许`in_out`方向使用`retain`。

修复方法：去掉`in_out`方向参数的`retain`属性。

**错误类型3：in方向参数在代码中被赋值（Error 1034）**

`SET_AUTO`最初方向设为`in`（只读），但代码中有`SET_AUTO := SET_A`的赋值语句，导致报错。

修复方法：将方向从`in`改为`in_out`，允许在代码中读写。

**错误类型4：FB引脚名写错（Error 1024）**

这是最容易犯的错误。标准功能块的引脚名有固定的拼写和大小写：
- RS触发器的复位引脚是`R1`，不是`Reset1`也不是`R`
- SR触发器的复位引脚是`Reset`，不是`R1`
- 定时器输入是`In`（首字母大写），不是`IN`
- 触发器输入是`Clk`，不是`IN`也不是`CLK`

修复方法：逐一核对每个FB调用的引脚名，参照开发规则中的引脚速查表修正。

**错误类型5：FB实例未在FUN表中声明（Error 1023）**

ST代码中调用了`Dint_bool16_1`、`BOOL16_DINT_1`等FB实例，但最初没有在FUN表中声明。老功能块用FBD方式时这些实例由图形自动处理，改成ST后必须手动声明。

修复方法：在FUN表中补全所有ST代码中调用的FB实例，包括Dint_bool16、BOOL16_DINT、TP、RS、SR、TOn、TOf、F_Trig、AlarmCond、SimpleEventDetector、TimerU等。

**错误类型6：ST语法错误（Error 1023/1104/1116）**

- 函数调用最后一个参数后面多了一个逗号（尾随逗号），800XA不允许。
- `);`单独写在了一行，必须跟在最后一个参数后面。

修复方法：检查所有多参数FB调用，删除尾随逗号，把`);`移到最后一个参数同一行。

经过逐条排查和修复，18个编译错误全部消除，两个功能块均编译通过。

完整的错误对照表见同目录下的《开发规则.md》和《ABB_800XA_FB开发规则2.md》中"常见错误速查"章节。

## 四、关键技术决策

在开发过程中，有几个关键技术决策值得特别说明，它们直接影响功能块的可靠性和可用性。

### 决策1：使用Dint_bool16/BOOL16_DINT拆分16位字

**背景**：变频器通过PROFIBUS DP传上来的控制字和状态字都是16位整数（DINT），但我们需要按位访问每一位的含义（如状态字bit3=故障、bit8=运行中）。

**标准库的问题**：800XA标准库提供了`DINTTOBOOL16`和`BOOL16TODINT`，但它们的接口设计不好用——输入输出用的是`Boolean16`结构体类型，而且带`Status`状态输出，变量声明繁琐。

**TAYNINH库的方案**：项目使用的TAYNINH库中有两个自定义功能块：
- `Dint_bool16`：输入1个DINT，输出16个独立的bool（bool0~bool15）
- `BOOL16_DINT`：输入16个独立bool（IN0~IN15），输出1个DINT

这样每个位都是独立的布尔变量，命名清晰（如`INBOOL1_B3`表示状态字第3位=故障），代码可读性大幅提升，也不需要再声明`Boolean16`结构体变量和`_STA`状态变量。

代价是FB调用的参数较多（16个），但通过合理的命名和注释可以很好地管理。低压功能块用了2个Dint_bool16实例（解析状态字和ACT1），中压功能块用了3个（多解析一个ACT2）。

### 决策2：500ms延时使能OPERATION_ENABLE位

**背景**：ABB变频器的状态机有一套固定的转换流程，不能一步到位地发"运行"命令。完整的状态机转换序列是：

```
NOT READY → SWITCH ON INHIBIT → READY TO SWITCH ON → READY TO OPERATE → OPERATION ENABLED → AT SETPOINT(运行)
```

**问题**：如果同时把控制字的bit0（OFF1=运行）和bit3（OPERATION_ENABLE=允许运行）都置1，变频器可能无法正确完成状态转换，导致启动失败。

**解决方案**：在驱动命令（drive）发出后，用TOn定时器延时500ms，再把控制字bit3（OPERATION_ENABLE）置1。这样状态机有足够时间完成"准备合闸→准备操作"的转换，然后再使能运行。

代码实现：
```pascal
TOn_1(
    In := drive,        (* 驱动命令发出 *)
    PT := T500ms);      (* 延时500ms *)

OUTBOOL1_B3 := TOn_1.Q; (* 500ms后使能OPERATION_ENABLE *)
```

这个500ms是经验值，实测在FPBA-01和RPBA-01上都能可靠工作。如果驱动响应较慢，可以适当增大此值。

### 决策3：SET_AUTO实现本地/自动无扰动切换

**背景**：粉磨站的变频器有时需要由DCS自动控制（按工艺设定值运行），有时需要操作员在画面上手动调整频率。两种模式切换时，如果给定值突变，会造成电机转速跳变，影响生产。

**解决方案**：设计了SET_AUTO（自动给定）和SET_L（本地给定）两个参数，通过EXTINPUT（外部/本地切换开关）来选择：

```pascal
IF EXTINPUT THEN
    SET_A := SET_AUTO;   (* 外部模式：使用自动给定 *)
ELSE
    SET_A := SET_L;      (* 本地模式：使用本地给定 *)
END_IF;
```

同时实现跟踪逻辑，确保切换时无扰动：
```pascal
(* 非外部模式时，SET_AUTO跟踪当前给定，保证切回自动时无突变 *)
IF NOT EXTINPUT THEN
    SET_AUTO := SET_A;
END_IF;
```

本地模式下，操作员可以通过Freq_Up（频率+）和Freq_Dn（频率-）按钮每次调整0.2Hz，实现精细微调。

### 决策4：中压版增加温度监控、急停定时器、多控制模式

中压变频器功率大、电压等级高，安全要求比低压更严格，因此中压功能块额外增加了三项功能：

**1）电机温度监控**

中压变频器的电机温度是一个关键安全参数。通过RPBA-01参数916将电机温度映射到PZD6（INPUTDINT6），代码中实时读取并换算：

```pascal
motor_temp := DINT_TO_REAL(VVVFDINT.INPUTDINT6.Value) / 10.0;

RS_4(
    Set := (motor_temp > temp_Limit) AND RUNNING,
    R1 := Reset);
TEMP_ALARM := RS_4.Q1;
```

当电机温度超过`temp_Limit`且变频器正在运行时，触发温度报警（TEMP_ALARM）并锁存，直到操作员复位。

**2）急停定时器**

中压变频器的急停（OFF3快速停车）需要一个可配置的时间延时，用于安全联锁。低压功能块的急停是直接把控制字bit2置0，而中压版增加了一个TOf断电延时定时器：

```pascal
TOf_1(
    In := EMG_stop,
    PT := ES_TIME);

OUTBOOL1_B2 := NOT TOf_1.Q;  (* 延时后触发OFF3 *)
```

`ES_TIME`参数可以根据工艺要求配置急停延时时间。

**3）多控制模式**

低压功能块只支持频率（Hz）给定，而中压变频器在不同工艺场景下可能需要用转速（rpm）或百分比（%）来设定。中压版通过`set_type`参数选择控制模式：

```pascal
CASE set_type OF
    0: (* 频率模式：SET_A为Hz，换算出转速和百分比 *)
    1: (* 转速模式：speed_ref为rpm，换算出频率和百分比 *)
    2: (* 百分比模式：percent_ref为%，换算出频率和转速 *)
END_CASE;
```

操作员可以灵活选择最直观的单位来输入给定值，功能块内部自动完成单位换算。

## 六、使用方法

以下是在800XA工程工具中导入和使用这两个功能块的步骤。

### 6.1 导入功能块

**第1步：导入GSD文件**

在800XA工程工具的硬件组态中，将GSD文件导入PROFIBUS DP从站库：
- 低压变频器：导入`ABB10959.gsd`，设备标识号0x0959
- 中压变频器：导入`ABB10812.GSD`，设备标识号0x0812

**第2步：导入数据类型**

导入`VVVFDT_DataType.xlsx`定义的VVVFDT数据类型。此数据类型对应PPO4报文格式（0 PKW + 6 PZD），包含6个输入DINT和6个输出DINT。

**第3步：导入TAYNINH库自定义FB**

确保TAYNINH库已加载到工程中。需要确认以下自定义FB类型可用：
- `Dint_bool16`（DINT转16个bool）
- `BOOL16_DINT`（16个bool转DINT）

如果库中没有，需先导入`Dint_bool16_par.xlsx`和`BOOL16_DINT_PAR.xlsx`。

**第4步：导入功能块文件**

在800XA的功能块编辑器中，分别导入低压和中压功能块：

低压（ABB_LV_VVVF）：
1. 导入`ABB_LV_VVVF_VAR.xlsx` → 变量声明
2. 导入`ABB_LV_VVVF_PAR.xlsx` → 参数声明
3. 导入`ABB_LV_VVVF_FUN.xlsx` → FB实例声明
4. 将`ABB_LV_VVVF_Code.st`的Code段内容粘贴到Code编辑区
5. 将`ABB_LV_VVVF_Code.st`的Code2段内容粘贴到Code2编辑区

中压（ABB_MV_VVVF）：
1. 导入`ABB_MV_VVVF_VAR.xlsx` → 变量声明
2. 导入`ABB_MV_VVVF_PAR.xlsx` → 参数声明
3. 导入`ABB_MV_VVVF_FUN.xlsx` → FB实例声明
4. 将`ABB_MV_VVVF_Code.st`的Code段内容粘贴到Code编辑区
5. 将`ABB_MV_VVVF_Code.st`的Code2段内容粘贴到Code2编辑区

**第5步：编译验证**

编译功能块，确认无错误无警告。如果出现错误，请参照《开发规则.md》中的"常见错误速查"表排查。

### 6.2 在程序中调用功能块

在PLC程序中，像调用普通功能块一样调用ABB_LV_VVVF或ABB_MV_VVVF。将功能块的VVVFDINT引脚连接到PROFIBUS DP从站的I/O映射地址，其余引脚按需连接：

- 控制信号（Group_start、Single_start、Single_stop、Reset、EMG_stop等）连接到操作员画面按钮或联锁逻辑
- 状态信号（READY、RUNNING、FAULT、Frequency、Current等）连接到操作员画面显示或报警系统
- 给定信号（SET_AUTO、SET_L）连接到工艺控制回路或操作员画面输入框

### 6.3 硬件组态注意事项

在PROFIBUS DP硬件组态中，需要正确配置变频器通信适配器的报文格式：

- **PPO类型**：选择PPO 4（0 PKW + 6 PZD）或PPO 6（0 PKW + 10 PZD），与VVVFDT数据类型匹配
- **通信行规**：
  - 低压（FPBA-01）：确认参数51.27 = 0（ABB Drives行规）
  - 中压（RPBA-01）：默认PROFIdrive行规
- **实际值映射**：通过通信适配器参数916配置PZD字与驱动参数的映射关系，确保：
  - PZD2（ACT1）→ 输出频率（驱动参数1.06）
  - PZD3（ACT2）→ 电机电流（驱动参数1.04）
  - PZD5（ACT4）→ 电机功率（驱动参数1.14）
  - PZD6（ACT5）→ 电机温度（仅中压，驱动参数视具体型号而定）

### 6.4 调试建议

1. **先单台调试**：先用1台变频器验证通信是否正常，观察状态字（STATUS）的原始值是否符合预期。
2. **检查状态机转换**：启动时观察READY→RUNNING的转换过程，确认500ms延时后能正常进入运行状态。
3. **验证给定换算**：设定一个已知频率值，对比DCS显示的Frequency和变频器面板显示的频率是否一致。
4. **测试报警功能**：模拟故障（如断电、本地切换），确认报警正确触发和复位。
5. **中压额外测试**：验证电机温度读取是否正常，测试急停定时器延时是否符合要求。
