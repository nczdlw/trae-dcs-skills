# 越南 F163 莱歇磨 800xA 程序整改说明

整改日期：2026-07-28  
正式依据：`E12893-1602-9007-00 Interlocking diagram VP`、最新版仪表清单、消费者清单。

## 三、建议导入和执行顺序

1. 在 ABB Control Builder 中备份现有应用、库版本和在线参数。
2. 导入 `NEW_CEMENT_CORRECTED.VAR.xlsx`。
3. 导入 `NEW_CEMENT_CORRECTED.FUN.xlsx`。
4. 在 FBD 中补接新增的 SignalInReal 阈值状态、PID、设备实例和外部接口。
5. 依次放置并执行 ST：`P98 → P101 → G20 → G40 → G50 → G55 → G30 → G58 → G62 → G10 → G60 → G65 → G71`。
6. 执行 **Complete Check**，处理所有库版本、管脚名和任务连接差异。
7. 离线仿真全部启停、故障、急停、断线、低液位、低流量、超温和超时场景。
8. 现场单机和联动试车后，再将参数状态改为“已确认”。

## 四、必须完成的 FBD 接线

### G30 压力投票

每个 `PI11…PI26` 必须分别提供：

- `*_L2`：低低压力状态；
- `*_H1`：高压一级状态；
- `*_H2`：高压二级状态；
- `*_SL1_OK`：压力高于启动释放值。

不得再把四种状态合并成一个 `T_L` 或 `T_H`。

### G65、G71 PID

- G65：`N562WI5PID`，SP=`N562_WI5_PID_SP`，PV=`N562_WI5_PID_PV`，输出=`N562_WI5_PID_OUT`。
- G71：`N562GD1PID`，SP=`N562_GD1_PID_SP`，PV=`N562_GD1_PID_PV`，输出=`N562_GD1_PID_OUT`。
- 两个 PID 的输出单位均为变频器速度百分比，不能把 m³/h 或 l/min 直接接到变频器速度设定。

### 外部接口

以下信号必须来自设计院/喂料组程序：

- `N562_RMF_ON`
- `N562_RMF_OFF`
- `N562_MAT_IN_MILL`

以下信号必须来自独立硬件点：

- `N562_RM1_VI_OK`
- `N562_RM1_VS02`

## 五、投运前尚需确认

1. G65 正式连锁图使用 LS03、LS04，最新版仪表表仅列 LS01，必须确认实际液位开关和 I/O。
2. G30 的 64 个阈值状态必须与 SignalInReal 管脚逐点对应。
3. G50/G55 的建压值 80 bar、辊位 300 mm 为沿用初值，需 Loesche/调试批准。
4. G65 的低流量初值 0.8 m³/h 取量程下限，仪表表未给 L2，必须批准后投运。
5. G71 的 MT01、MT11、FI01、GS/LS、SO、GI 和比例阀实际 I/O 地址需按柜图分配。
6. G65/G71 PID 的 K、Ti、输出上下限、手自动切换和无扰切换需现场整定。
7. P101 的 VI01:OK、VS02 极性和 PQSTOP 延时需做硬接线跳闸试验。
