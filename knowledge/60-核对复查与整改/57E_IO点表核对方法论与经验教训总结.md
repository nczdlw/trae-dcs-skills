# 57E IO点表核对方法论与经验教训总结

## 一、四部分核对方法论

### 第1部分：MV中压核对
- **输入**: MV图纸 (MV-01~04)
- **对照**: 电气原理图
- **提取信号**: 中压开关柜保护、控制、测量信号
- **信号类型**: DI(故障/跳闸/合分闸状态) + AI(电流/功率/电压)

### 第2部分：LV低压核对
- **输入**: SLD单线图 (SLD-01~21)
- **对照**: SINOMA-NCDRI电气原理图ES220
- **提取信号**: 低压电机、变频器、控制箱的DCS信号
- **信号类型**: DI(运行/故障/就地远程) + DO(启动/停止) + AI(电流) + RTD(温度)

### 第3部分：CC外部接线核对
- **输入**: CC外部接线图 (CC-01~30)
- **提取信号**: 所有标注到DCS的接线信号
- **关键**: 注意复合标签(如57.02LS01~09)需要展开为个体信号

### 第4部分：IL仪表核对
- **输入**: IL仪表清单Excel + TA2020-1单元接线图册
- **提取信号**: 
  - 标准DCS信号(DI/DO/AI/RTD/AO)
  - PA(Process Analytical)信号 → 单独工作表
  - IL中参考CC图的信号 → 需要与CC部分交叉验证
- **TA2020-1配套信号**: ZT/ZS/DA阀门需要补充ZSO/ZSC/DOO/DOC等限位开关信号

## 二、关键经验教训

### 1. 复合标签处理
- **问题**: IL清单中存在大量复合标签(如57.02LS01~09)
- **解决**: 必须展开为个体信号(DI5702LS01, DI5702LS02...)
- **注意**: 展开时要保持正确的编号格式(补零等)

### 2. PA仪表单独统计
- **问题**: PA仪表信号原本混在AI中
- **解决**: 在IO点表中单独创建PA工作表
- **原因**: PA是硬线连接到DCS的分析仪表，与标准AI不同

### 3. IL-CC交叉引用验证
- **问题**: IL清单中SCHEMATIC DIAGRAM列包含CC图引用
- **解决**: 必须验证这些信号是否已在IO点表中
- **方法**: 提取IL中所有CC引用 → 展开复合标签 → 检查IO点表覆盖

### 4. 重复信号清理
- **问题**: 同一信号可能从多个来源添加，导致重复
- **解决**: 定期运行重复检查脚本
- **注意**: 删除重复后需要重新编号

### 5. Cover页同步更新
- **问题**: 添加信号后Cover页统计未更新
- **解决**: 每次修改后更新Cover页各工作表的计数

### 6. 信号命名规范
- **格式**: [类型][区域][设备][后缀]
- **示例**: DI5702LS01, RTD5716TT01, AI5716PT01
- **注意**: 区域号要去掉小数点(57.02 → 5702)
