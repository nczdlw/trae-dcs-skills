## 三、盘点结论

1. **可动的只有一处核心**：#1 complex-task-decompose 是唯一同时混装四类内容的资产（通用内核 + TRAE 路径 + DCS 入库规则 + Git 副作用），是解耦对象；#2 虽是领域技能但边界清晰，本阶段不动。
2. **两份模板与 #1 同源**：任务树模板内嵌于 SKILL.md 第五节，改 #1 必须同步 #3/#4，否则出现第二份漂移模板（TRAE 副本漂移已是先例）。
3. **knowledge/70 分类 8 篇是“经验条目形态的方法论”**：保持 E 类定位不变（可检索、有 frontmatter、进 INDEX），不升级为 skill——避免每个方法论都变成技能造成膨胀。
4. **AI任务管理/ 历史档案与 knowledge 有重叠风险**：历史任务树的过程产物按 TIL 原则不重复入库；本任务产物只入 1 条 consolidated 条目（L1-5.2）。
5. **平台适配资产现状**：TRAE 有实体安装（#8+#9+#1 副本），WorkBuddy 无任何安装——跨平台空白是事实，不是文档缺失。
