## 三、回滚步骤（按场景）

**场景 A：仓库改错了，想全部退回**
1. `git -C D:\.AI\GITHUB\trae-dcs-skills stash` 或 `git reset --hard 8534900`（未提交时用 stash，保留现场待查）。
2. 已提交但未推送：`git revert <commit>`；已推送：`git revert` 后推送（推送需用户授权）。

**场景 B：只退回核心 skill**
1. `cp 素材\SKILL_原版_20261014.md → complex-task-decompose/SKILL.md`
2. 删除 `complex-task-decompose/references/` 与 `docs/通用方法论迭代/`（如确认不需要证据留档）。
3. 模板若已同步改错：从 8534900 取回 `git checkout 8534900 -- templates/任务树模板.md templates/任务接续指令模板.md`。

**场景 C：TRAE/WorkBuddy 副本改错了**
1. TRAE：把 `.bak-20261014` 复制回 `~/.trae-cn/skills/complex-task-decompose/SKILL.md`。
2. WorkBuddy：删除 `~/.workbuddy/skills/complex-task-decompose/` 即恢复“未安装”原状。

**场景 D：README/知识库改错**
1. README：`git checkout 8534900 -- README.md`。
2. 知识库：删除新条目文件 + `git checkout 8534900 -- knowledge/INDEX.md`。
